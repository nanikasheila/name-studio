# name-studio

ネーム（漫画の絵コンテ）制作専用ツールです。CLIP STUDIO PAINT 本体には触らず、
.clip / .cmc ファイルの読み書きだけで CSP とつながります。ペン入れ以降は今までどおり CSP で行います。

構想と段階計画は [検討ドキュメント](https://claude.ai/artifact/PhzqeXUZhD9LZs2pbkRsLs) にあります。
ファイル形式の解析結果は csp-name-splitter の
[docs/formats/csp-file-format.md](https://github.com/nanikasheila/csp-name-splitter/blob/main/docs/formats/csp-file-format.md) を参照してください。

## はじめかた

1. [最新のリリース](https://github.com/nanikasheila/name-studio/releases/latest) から
   `NameStudio_…_x64-setup.exe` を落として入れます（Windows 10 / 11。署名していないので、初回は
   SmartScreen の「詳細情報 → 実行」で進めます）。入れたあとは起動するたびに自動で更新されます。
2. 開始画面で「新しいネーム」（白紙から）か「開く」（CSP のネーム用紙 .clip から取り込む）。
   左の道具で、コマ割り（線を引いて割る）→ セリフ（クリックで置く）→ ペン（ラフを描く）。
   変更は自動で保存され、ネーム名の横に保存の状態が出ます（最初の Ctrl+S で保存先を決めます）。
3. 右上の「書き出す…」で、書き出し先を選んで「書き出す」。CSP のページ（.clip）と作品（.cmc）が
   できるので、CLIP STUDIO PAINT EX で作品を開いてペン入れに進みます。打ち合わせ用の PDF もここから。

迷ったら Ctrl+K（命令パレット）で、やりたいことを打って探せます。窓の下の「ヘルプの帯」にはポインターの下にあるものの名前とマウス・キーでできることが、? （右上のボタン）では画面の各部の名前と使い方が出ます。

## できること

- CSP のネーム用紙（.clip）を開いて、全体表示と右綴じの見開き表示で見直す
- ページ枠（テンプレートの四角形）から 1〜N ページを自動で割り当てる
- レイヤーの表示切り替え、ページごとのセリフ一覧（縦書きで表示）
- ネーム用紙をページごとの .clip と作品ファイル（.cmc）に書き出す（レイヤーを保ったまま）
- ネームデータ（.namestudio）の編集。ネーム用紙から取り込むか、白紙から作る
  - ネーム用紙からの取り込み: 題名はその用紙をページに持つ作品（.cmc）の名前、なければ作品名と話数。余白の文字はセリフにせずページのメモに。後ろの空のページは除くか聞く
  - コマ割り: コマを横切る線で割る（間白つき、斜めも可）、囲んで新しいコマ、角をドラッグして形を変える（枠に吸い付く）
  - セリフ: クリックで置く、縦書き・種類（セリフ／モノローグ／ナレーション／描き文字）・話者・文字の大きさ。フキダシは文字に合わせて伸び縮み
  - ラフ: ペン（筆圧つき）と消しゴム。取り込んだネーム用紙のラフ画像を下に薄く表示
  - ページの追加・削除・並べ替え（ページの欄の下で枚数を決めてまとめて足す。1 回の Ctrl+Z で戻る）、ページのメモ、台本（全セリフを読み順に。上の欄でセリフの言葉や話す人で探せる）、登場人物
  - 付箋（左の「付箋」）: 全ページの付箋を一覧に。押すとその付箋へ、決まったら「済み」で外す。長い付箋はページの上では頭の 4 行（…）にたたみ、選ぶかポインターを乗せると全文
  - 付箋の紐づけ: 付箋ツールでコマやセリフの上をクリックすると、そこに紐づいた付箋（表計算のコメントのように）。付箋はどこへ動かしても線でその場所とつながり、コマやセリフを動かすと付いてくる。選んだ付箋の丸をほかのコマ・セリフへドラッグで付け替え、何もない所で外す。コマのメモの札もドラッグでコマの外へ動かせる（線でつながる）
  - 保留コマ（左の「保留」）: コマの操作バーの「保留」で、中身（セリフ・ラフ線・塗り・付箋）ごとページから外し、そのページの上の欄外に置いておく（一覧の「欄外に置く／欄外から下げる」でも出し入れ）。「このあたりのページ」を決めておくと、そのページを開いたときに下の帯とページ一覧に出る。ページへドラッグで戻す（コマの上で離すと中身をそのコマへ合わせて入れる。ドラッグ中は、入れるコマ・置く場所・欄外のどれになるかを枠と言葉で出す）。命令「選んだコマを中身ごと保留にする」にキーを割り当てられる。操作バーの「移す…」で、中身ごと別のページの同じ位置へ
  - 欄外（ページの外）: 紙のネームの余白のように、ページの外にも書ける。ペンで考えごとやイメージのラフ、付箋ツールでメモ、資料画像（ページの外へドラッグ、ページの外で貼り付け・ファイルを落とす）、保留コマを置ける。どれもいちばん近いページのものとして一緒に動き、「連続」では欄外の分だけページの間が広がる。消しゴム・選択・移動もそのまま使える。保留コマは欄外からページへドラッグで置ける（コマの上で離すと中身をそのコマへ）。欄外のものは CSP には書き出さない（CSP のページは紙の端までなので。ページから少しはみ出した線はこれまでどおり書き出す）
  - 資料画像（左の「資料」、I）: 写真・背景・前に描いたコマなどをページの下に薄く敷いて、その上にネームを描く。「画像を貼る…」、Ctrl+V（クリップボードの画像。ポインターのあるページへ）、画像ファイルのページへのドロップで貼る。資料ツールでドラッグして動かし、角で大きさ（形はそのまま）、上の段で濃さ・外す（Delete）。画像は大きすぎるものを縮めて（長辺 2400px、写真は JPEG）ネームのファイルに 1 度だけ入る（使っていないものは保存しない）。CSP へは一番下の「資料（ネーム）」下描きレイヤーで出る。PDF には入らない
  - セリフのマスク: 操作バーの「マスク」か右の欄の「コマ枠でマスク」で、コマの外に出たフキダシと文字を枠で切る（画面・PDF・CSP のフキダシの線も）
  - 人物: 口調のメモ（セリフを選ぶと右の欄に出る）、数を押すとその人のセリフを並べて見比べ、押すとそのセリフへ
  - コマやセリフを選んでいる間も、右の欄の上にそのページのメモ（プロット）を出す
  - Markdown の台本の取り込み（左の「台本」）: ページ・コマ・セリフ・ト書き。長いセリフは自動で改行して台本のコマの中に置く（文の切れ目「。！？」では必ず改行、細いコマでは細く・少し小さく）。`### 5ページ` のようにページ番号があれば、そのページから入れる。台本を直して取り込み直すと、セリフのあるページは台本に合わせて直す（変わったセリフだけ書き換え・足す・消す。位置・形・しっぽはそのまま。足したセリフはラフの顔とほかのフキダシをよけて置く。取り込む前に件数を出す。コマのメモの書き換えも数える）。アプリが書き出した台本（■ / ［N］）を直して取り込み直しても同じで、セリフ中の全角スペースは改行として読む。ページはセリフの似ている度合いで突き合わせるので、台本でページを足すとその位置にページを入れ、後ろのページはずれない（台本から消したページはそのまま残して知らせる）。フキダシを動かして読む順が変わっていても、似ているセリフ同士を組にする。`### 1ページ 副題` の副題はページのメモに。`名前〔電話〕「…」`（電話・無線 → 電子音、叫び → トゲ、小声 → 破線、独白 → モノローグ）、`「…！！」` はトゲ
  - 元に戻す・やり直す（Ctrl+Z / Ctrl+Shift+Z）、保存（Ctrl+S）
  - 命令パレット（Ctrl+K）: 命令の名前を少し打つと探せて、Enter で実行。キーも横に出る。コマ割りの作り方（割る・四角・多角形）・保留・読み戻し・次の話・読む表示も命令になっていて、「キー設定」でキーを割り当てられる。ひらがな・カタカナ・全角の違いは気にしなくてよく、最近使った命令が先に出る。いま使えない命令は薄く出る
  - 開始画面: 最近開いた・保存したネームを新しい順に並べ、ワンクリックで開き直せる（ページ数といつ開いたかも出る。× で一覧から外す。開けなくなったものは自動で外れる）。開始画面でも Ctrl+K で「開く」「新しいネーム」と最近のネームを名前で探せる
  - 書き出しの設定はネームごとに覚える（書き出し先・ひな形・コマの書き出し方・レイヤーの選択・PDF/台本のファイル）。次に書き出すときはそのネームの前回の設定から始まり、別のネームの書き出し先を引き継いで上書きすることはない。「前回と同じ設定で書き出す」（Ctrl+Shift+E）で、何も聞かずに前回と同じ書き出しをもう一度（CSP で描き進めたページを上書きしそうなときだけ確認する）。書き出している間は「中止」でページの切れ目で止められる（PDF は何も書かずに、CSP は書き終えたページまでで止め、作品ファイルは前のまま）
  - 書き出し（「書き出す…」）
    - CSP のページ: ページごとの .clip（ラフ線・コマ枠・フキダシ・セリフ・取り込んだラフ画像を別レイヤー）と作品ファイル（.cmc）。ネームの基本枠をひな形の基本枠に合わせる
    - ひな形なしで書き出せる（既定の「ツールで設定する」）: 用紙（商業誌 B4・A4・B5・A5 か手入力）・キャンバス・仕上がり・裁ち落とし・基本枠（大きさとずらし）・解像度・1 ページ目の左右・作者名・ノンブルの開始番号・作品情報のフォント・サブタイトル・作品名と作者名の位置・ページ番号・見えるノンブル（位置・色・フチ・書式・間隔・大きさ）を書き出し画面で決めると、アプリに入っている CSP 製の白紙からページと作品ファイルを作る（設定はネームに保存。綴じ方はネームの読む向き）。CSP で保存したひな形を使うこともできる（「CSP のひな形を使う」）
    - 書き出す前の確認: フキダシの重なり・コマの外のセリフ・コマからはみ出したセリフ・仕上がりの外・しっぽのないセリフ・ラフの顔にかかるセリフを一覧にし、押すとそのセリフへ。はみ出しは「はみ出したセリフのコマを並べ直す」でまとめて改行し直す。顔にかかるセリフは「顔にかかるセリフをずらす」で、そのセリフだけ顔とほかのフキダシをよけてずらす（よけきれないコマは並べ直す）
    - PDF: 全ページを 1 つの PDF に（右綴じなら右から開く指定つき）
    - 台本: ページ・コマ・話者つきのテキスト
  - 一画面: 編集しながら全体が見える。画面の切り替えはなく、ページの下に「物語の帯」、右の欄に選んだものが出る
    - 物語の帯: 話の型・シーン・時系列・感情曲線・字数・ページとコマを、同じページの並びに重ねて出す。はじめはシーンとページだけで、ページに窓の高さの 7 割ほどを残す（描く配置。それより低い窓、例えば高さ 900 px では、たたんで始める。帯のボタンはページのすぐ下の段の右にあり、F2〜F4 で段を足す、F6 で大きく、Shift+F6 でたたむ・広げる。自分で開いた・たたんだ・高さを変えたときはそれを覚える）。いま開いている見開きに枠が付き、ページやコマを押すとそこを上に開く。区切りやシーンの端・時系列の棒・感情の線をドラッグ、ページ番号の帯でページを移動、コマを別のページのコマへドラッグで中身（絵・セリフ・塗り・メモ）を入れ替え。帯の上の段のアイコンで出すレーンを選ぶ（F2 シーンと字数、F3 感情、F4 時系列）。上端のドラッグで高さ、F6（か上端のダブルクリック）で大きく・戻す（F1 で元の高さ）。Ctrl＋ホイールで拡大縮小、ホイールで横へ
    - 右の欄: 帯でシーンを押すと名前・物語の中の時・あらすじ・ページ・人物ごとの感情の線、「型」を押すと話の型・目標ページ数・区切り・ビート。何も選んでいないときのページの欄に、そのページの型の区切り・シーン（押すとシーンの欄へ）と感情の値・メモ
    - 話の型: 起承転結・三幕構成・序破急・Save the Cat（ビート付き）と、自分の型（区切りの名前・配分・色・ビートを決める。このネームとこの PC に保存され、ほかのネームでも選べる）。ページ一覧と帯のページは型の区切りで色分け
    - プロットの取り込み（「台本」タブ）: Markdown のプロット（### 1ページ 見出し＋本文、ページ配分の表、論点などの節）をページのメモ・シーン・付箋・目標ページ数に振り分け、帯を大きくして見せる。ページを書いていない論点の付箋は、中身の近いページ（見出しと本文の言葉で選ぶ）へ、重ならないように並べる（見開きで隠れないよう、ページの外側＝右ページは右端・左ページは左端に）。台本（#### コマとセリフ）か、プロットかは中身を見て決める。プロットのあとに台本を取り込むと、重なるシーンは台本のシーンに置き換わる（同じページ範囲なら要約を引き継ぐ）
    - 感情曲線は値のないページをまたぐところを点線に。帯の人物の丸で、なぞる人物を選ぶ。「話す所に点」でその人物が話すページに、前後の値の間をとって点を打つ
    - 新しいネームは作品名・ページ数・目標ページ数・話の型を聞いてから作る
  - 画面の配置: 道具は左の縦の列、その道具の設定（ペンの種類・太さ・消し方・塗りの色）はページの上の 1 段、ページ送りと見開き／単独・コマのメモはページのすぐ下の段、その下に物語の帯。欄（ページ・台本・人物・付箋・保留・レイヤー・詳細）は CSP のパレットのように左右どちらの列にも置け、いくつでも同時に上下に並べて開ける。列の上のアイコンで出す・隠す、見出しのドラッグで別の場所や反対側の列へ（見出しの矢印でも左右へ）、見出しのダブルクリックでたたむ、間の線のドラッグで高さ、列の内側の端のドラッグで幅、「‹」で列ごとアイコンだけに。並びは次に開いたときも同じ。道具を変えてもほかのボタンは動かない。右の欄は選んだもの（コマ・セリフ・付箋など）の色とアイコンで、長い説明は「?」で開く。ページ一覧はコマ割りの図（セリフが多いコマほど濃い）
  - 単独ページ表示: 下の帯の「単独」で 1 ページずつ大きく（見開きに戻すのは「見開き」）
  - 連続（一枚のキャンバス）: ページの下の段の「連続」（F7）で、紙のネームのように全ページを一枚に並べる。見開きごとに読む順（右綴じは右から左）、行は上から下。行数はつまみ（Alt+↑ / Alt+↓）でなめらかに変わり、1 行なら全ページが横一列に、増やすほど格子になって俯瞰しやすい。いま描いている見開きは画面の同じ場所に残る。どのページにもそのまま描け、ペンの線はページやノドをまたぐとそれぞれのページに分かれる。セリフ・ラフ線・コマ（中身ごと）は別のページへドラッグで移る（動かしている間はページの間や移る先のページの上にも見え、移る先のページに枠と「N ページへ」が出る）。ホイールで拡大縮小（ポインタの下のページは動かない）、Shift＋ホイールで行に沿って、Ctrl+Alt+0 で全ページを画面に、Ctrl+0 でいまの見開きを大きく。触ったページの見開きが右の欄と帯の枠になる。小さく見ているときはコマ番号やメモを出さず絵だけにする
  - 文字の大きさ: 右の欄の文字の大きさの上でホイールを回すと、その場でページに出る。ページの上で Alt＋ホイールでも、選んだセリフの文字の大きさが変わる
  - 読む（F5）: ページの下の段の本のボタンか F5 で、ネームを窓いっぱいの見開きで通し読みする。付箋・メモ・コマ番号・選択・枠は出さず、読者や編集者が見るままに。← → で読む向きにめくり（右綴じは ← が次）、クリック・タップは読む先の側（右綴じは左半分）で次へ、スワイプやホイールでもめくる。Home / End で最初・最後、Esc（または F5）で最後に読んでいた見開きのまま編集に戻る
  - 道具の切り替え: V 選択、K コマ割り、T セリフ、P ペン、E 消しゴム、G 塗り、B はみ出し、M 付箋、I 資料。キーを押したままにすると CSP のようにその間だけ持ち替え、離すと元の道具に戻る（押したまま使ったときも。描いている途中で離したら描き終わりで戻る）。短く押すと持ち替えたまま。Space＋ドラッグで移動、ホイールで拡大縮小、Shift＋Space＋ドラッグ（または - と ^）で画面を回す、Ctrl+0 で全体表示、Tab で左右の欄と下の物語の帯を隠してページを窓いっぱいに（もう一度で戻す）。キーは「キー設定」で変えられる
  - コマの変形: 選択ツールでコマの境目（間白）をドラッグすると両側のコマが一緒に動く。外側の辺は辺だけ動く。境目をダブルクリックで隣のコマとつなげる。選んだコマの角をドラッグで形を変える（台形など）
  - 吸着: コマの移動・角・辺・拡大縮小とコマを描くとき、隣の角と水平・垂直、ほかのコマの辺の線とその外側のコマ間ぶん、基本枠・裁ち切り線・用紙の端、グリッドに吸い付く。吸い付いた線はピンクの点線で出る。Alt を押している間は吸着しない。どれに吸い付くか・グリッドの間隔は「設定」で、グリッドの入り切りはコマ割り道具の段でも
  - コマを足す: コマ割り道具の段で「割る」（横切るように引いて割る。Shift＋コマの外のドラッグで四角いコマ）・「四角」（ドラッグで四角いコマ）・「多角形」（クリックで角を置き、最初の角・ダブルクリック・Enter で閉じる。Backspace で 1 つ戻す、Esc でやめる）。コマの中に描いたコマは、はめ込み（白で上に重なる）
  - 左綴じ（海外コミック・横書き）: 新しいネームを作るときか「設定」の「読む向き」で選ぶ。見開きの左右（1 ページ目は右ページ）、コマとセリフの番号（左上から）、コマ割りの型（左右反転）、セリフの並べ直し・しっぽ・台本から作るコマとセリフ（左から右へ）、新しいセリフの横書き、← → キーとページ送りの向き、PDF の開き方が変わる。途中で切り替えると番号を振り直し、そろえる指定でセリフの縦書き・横書きも入れ替える（元に戻せる）。CSP の作品の綴じ方は作品のひな形に従うので、左綴じの作品をひな形にする
  - 縦スクロール（Webtoon）: 新しいネームを作るときに「読む向き」で選ぶ。縦に続く帯を幅 120 × 高さ 240 mm（スマホ 2 画面ほど）の区切りに分けて描き、区切りが 1 ページになる（見開きなし、コマ番号は上から、セリフは横書き、コマ間の上下は広め 24 mm）。「連続」では区切りがすき間なく縦につながった帯になり、ホイールで上下、Ctrl＋ホイール（ピンチ）で拡大縮小、つまみで帯を何列かに分けて俯瞰できる。線は区切りをまたいで描ける。CSP には区切りごとのページで、PDF は 1 列に続けて開く指定で書き出す
  - 設定（上の「設定」）: 左の一覧で分類を選ぶか、上の欄で探す（例: 太さ）。このネーム（ファイルに保存）: コマ割り（コマ間、枠線・太枠の太さ）、セリフ・フキダシ（種類ごとの文字の大きさとフキダシの形の既定、フキダシの線の太さ）、フォント（用途ごと）、読む向き。この PC: 表示（「連続」のページの間隔、コマのメモ、ヘルプの帯）、操作（コマと中身を一緒に動かす、フキダシの変形で文字の大きさも変える）、吸着、保存（自動で上書き保存）、ペン・キー。「新しいネームの既定にする」で、このネームの設定をこれから作るネームにも使う。1 つのコマの枠線の太さ・1 つのセリフのフォントは右の欄で、文字の大きさとコマの太さは右の欄の「既定にする」でも決められる
  - その場で書く: コマをダブルクリックでコマのメモ（ページの上に札で出る。書き出しには入らない）、セリフをダブルクリックかセリフツールでクリックで文字を直接。書いている間に Tab で決定して読む順で次のセリフ（コマのメモなら次のコマ）へ、Shift+Tab で前へ。ページをまたぐと見開きもめくれる
  - ヘルプ: 窓の下の「ヘルプの帯」に、ポインターの下にあるもの（道具・ボタン・コマ・セリフ・しっぽ・コマの境目・変形の枠・物語の帯の行など）の名前と、マウス・キーでできること（「ドラッグ 動かす」「ダブルクリック コマのメモを書く」「Ctrl+T 変形」）が出る。キーは「キー設定」で割り当てたまま、Shift・Alt・Ctrl・Space を押すとそれを使う操作が先に出る。帯の × か「設定 › 表示」で隠せる。? か右上の ? ボタンで「画面のヘルプ」（各部に名前と使い方とキーを重ねて出す。クリック・?・Esc で閉じる）。はじめて使うときは開始画面と編集画面で「使い方の案内」が順に各部を示す（→・Enter で次、← で前、Esc で閉じる。画面のヘルプ・設定・命令パレットからもう一度見られる）
  - 操作の決まり: Esc は 1 段ずつ戻る（書いている欄 → 変形 → 選択 → 資料画像 → 物語の帯で選んだシーン）。Delete は選んでいるものを消す（物語の帯で選んだシーンも。ページは残る）。ダブルクリックはその場で書く（セリフ・コマのメモ。付箋は右の欄の文字へ）。Ctrl+O で開く・Ctrl+N で新しいネームは、開始画面でも編集中でも同じ。ボタンにポインターを置くと、いま割り当てているキー（「キー設定」で変えたもの）が出る
  - 選択の決まり: 選んでいるものは、いつも青く強調して見せる。取っ手（コマの角・しっぽ・変形の枠）とそばの操作バーは選択ツールのときだけ出る。ほかのツールは自分で作ったものだけを選んだままにする（コマ割り＝コマ、セリフ＝セリフ、はみ出し＝はみ出し、付箋＝付箋）。それ以外の選択は、ツールを持ち替えると外れる（見えていない選択に Delete や矢印キーが効くことはない）。一覧・レイヤー・貼り付け・Ctrl+A でほかのツールのまま選ぶと、選択ツールに持ち替える。Esc は 1 段ずつ戻る（変形 → 選択 → 資料画像）
  - 選んだもののそばに操作バー。角やしっぽのないもの（ラフ線・塗り・はみ出し・まとめて選んだもの）は選ぶとすぐ変形の枠が出る。左右反転・90° は何を選んでいても効く（コマは中に描いたものと一緒に）。矢印キーはドラッグと同じ動き（コマは中身ごと。資料ツールでは選んだ画像）。Ctrl+C / X / V でコピー・切り取り・貼り付け（ポインターのあるページへ）、Ctrl+A でページのもの（コマ・線・セリフ・塗り・はみ出し）を全部選ぶ
  - ペンで Shift を押しながら引くと直線。塗りツールで囲んだ所をベタ・グレー・白で塗る
  - 変形（Ctrl+T か操作バーの「変形」）: コマとフキダシは、角やしっぽの代わりに枠を出して拡大縮小・回転、Ctrl + 角で自由変形。コマは中に描いたものと一緒に。Alt はいつも「吸い付かない」（コマの入れ替えは番号のドラッグで）
  - セリフを直す: 右の欄でもその場の書き込みでも、縦書きは右上（読み始め）を動かさずにフキダシが左下へ伸びる（しっぽの先はそのまま）。改行せずに打った長いセリフは、決定したときに句読点や助詞のあとで改行する
  - セリフを並べる: コマの操作バーの「セリフを並べる」、ページの「このページのセリフを並べ直す」で、読む順に右上から並べ直す（長いセリフは句読点や助詞のあとで改行。裁ち切りのコマでも基本枠の内側に。斜めのコマで細い端からはみ出すときは、収まるところまで寄せる。ラフに描いた人物の顔（頭のあたり）には重ねず、左か下へよける。アプリが改行したセリフは、改行を変えればよけられるときは改行し直す（手で改行したセリフはそのまま）。よけきれないときは重なりが一番少ないところへ）
  - 重なったセリフ: 同じ所をもう一度クリックすると下のセリフを選ぶ
  - 見開き: 左右どちらのページでも、クリックしたページが右の欄に出る
  - コマ割りの型を当てても、コマの中身（ラフ線・セリフ・塗り・メモ）は読む順に新しいコマへ移る（余った分は最後のコマに）
  - 型はコマ数を指定して当てられる（型の見た目のまま、段のコマをつなげる・割って合わせる）。台本の取り込みでも、選んだ型を台本のコマ数に合わせて作る。台本に `型：導入` と書いたページはその型
  - コマのメモ・ページのメモ・付箋は仕上がりの中に収まるように出る（コマのメモはフキダシを避けて角に）
  - フキダシの形を「〇〇の既定にする」と、その作品でその種類のセリフを作るときの形になる（独白は多角形、など）
  - まとめて選ぶ: Shift + クリックで足す・外す、Shift + ドラッグ（または何もない所からドラッグ）で囲んだものを選ぶ。選んだコマ・線・セリフ・塗り・はみ出しをまとめて動かす・拡大縮小・回転・自由変形・コピー・削除（コマは中に描いたものと一緒に）
  - しっぽを付ける: ページの欄か書き出す前の確認から、しっぽのないセリフ全部に。コマのラフの人物（線のかたまり）の頭へ向け、先に話す人ほど右の人物に。同じ話者は同じ向き。ラフがなければコマの下へ
  - しっぽ: どのしっぽも直接つかめる（途中をつかんで振る、ひし形で曲げる）。Alt + フキダシからドラッグで足し、先をフキダシに戻すと消える
  - レイヤー（左の欄）: 見開きのコマごとに中のセリフ・ラフ線・塗り（CSP のコマ枠フォルダのように）。行で選ぶ、目で画面から隠す、行をコマへドラッグで移す
  - ラフ線のレイヤー（レイヤーの欄の上）: ラフ線を「人物」「背景」「効果」などに分けて描く。＋で足し、行を押すとペンがそのレイヤーに描く。目で隠す、鍵でロック（描く・消す・選ぶができない）、つまみで濃さ、名前はダブルクリック、↑↓で並び、⤓で下と結合、×で線ごと消す。ページで選んだラフ線は「選んだラフ線をこのレイヤーへ」で移す。CSP へはレイヤーごとの下描きレイヤーで出る（隠したものは隠したまま、濃さもそのまま）
  - シリーズ（「シリーズ」の欄）: 何話ものネームで人物・ブラシ・フォント・作品の既定・CSP のページ設定・ラフ線のレイヤーを共有する。「シリーズを作る」でいまのネームを第 1 話にしてシリーズのファイル（`.nameseries`）を作り、「次の話を作る」で同じ設定の白紙の次の話を作る（ページ数は横の欄で決める。はじめはいまの話の目標ページ数、なければページ数。次の話の目標ページ数にもなる）。保存するとシリーズにも入り、ほかの話を開くとシリーズに合わせる（その話だけの人物も、セリフで使っていれば残る）。一覧の話を押すとその話を開く。すでにあるシリーズへは「シリーズに入れる」、外すのは「シリーズから外す」。ネームもシリーズの写しを持つので、シリーズのファイルがなくても開ける
  - ペンとタブレット（「ペン設定」）: 筆圧カーブ（描いて調節も）、傾き、消しゴム側、サイドボタン、指（1 本指で移動、2 本指で拡大縮小・回転、タップで元に戻す・やり直す、手のひらを無視）、カーソル

## 構成

| 場所 | 中身 |
| --- | --- |
| `crates/clip-core` | .clip / .cmc の読み書きのうちこのツールの規則（レイヤーの種類、ページ枠、ページ一覧、ネーム用紙の取り込み、書き出し、サブツールの描き味）。形式そのもの（コンテナ・DB・画素のブロック・テキスト・ベクター・自己検査）は [csp-format](https://github.com/nanikasheila/csp-format) の `csp-format`、サブツール（.sut / .todb）は `csp-assets` に任せ、ルートの `Cargo.toml` で rev を決めて使う（C の zlib をビルドするので C コンパイラが要る） |
| `crates/name-model` | ネームデータ（正本、.namestudio）。ページ・コマ・セリフ・ラフ線・シーン・登場人物・感情の値。CSP の形式もアプリも知らない（いちばん遅く変わる層。`clip-core/tests/layering.rs` が確かめる） |
| `crates/name-cli` | コマンドライン（`inspect` / `cells` / `import` / `split` / `decode-time`） |
| `app/` | 画面（Tauri 2 + TypeScript）。`app/src-tauri` が Rust 側 |
| `tools/compare_with_python.py` | Python 版（csp-name-splitter の `name_splitter/csp`）と出力を突き合わせる |

Rust 版は Python 版の移植で、Python 版を正解として同じ結果になることを確かめながら進めます。

## 使い方

Windows のインストーラーは GitHub Actions の「Release Windows app」が main ごとにリリースとして公開します（入れたアプリは自動で更新されます）。
署名していないため、初回は SmartScreen の警告が出ます。

開発する場合:

```bash
cd app
npm install
npm run tauri dev      # 画面を起動
npm run tauri build    # インストーラーを作る
```

コマンドライン:

```bash
cargo build --release -p name-cli
./target/release/name-studio-cli inspect page0001.clip --pixels
./target/release/name-studio-cli cells ネーム.clip
```

`inspect` の出力は Python 版の `csp-name-splitter inspect` と同じ JSON です。

アプリ自体も、画面を操作せずにネームを CSP へ書き出せます（書き出し画面と同じ処理。
終わると結果の JSON を書いて閉じ、読み直しで問題がなければ終了コード 0）:

```bash
name-studio-app --export-csp ネーム.namestudio (--template page.clip | --builtin) --out 書き出し先 \
  [--work-template 作品.cmc --work-name 第1話] [--story-index 1] [--donor 見本.clip] [--no-draft-rough] [--no-notes] [--frame-folders | --panel-masks] [--update-dialogue] [--report 結果.json]
```

`--builtin` はひな形の代わりに、ネームに保存した CSP のページ設定（書き出し画面の「ツールで設定する」、なければネームの用紙・600 dpi）でページを作ります。`--work-name` があれば作品ファイルも作ります（docs/builtin-template.md）。

線とセリフを CSP で直せるベクター・テキストのレイヤーにするには、CSP がそのレイヤーを作った .clip を見本にして写します。
ひな形、`--donor`（書き出し画面の「見本のページ」）、取り込み元のネーム用紙、ひな形と同じフォルダーのページの順に探し、
どれにもなければ csp-format に内蔵の見本（線 1 本とテキスト 1 つのページ）を使います。CSP が保存した空のページだけをひな形にしても、線とセリフは編集できるレイヤーになります。

ラフ線（はみ出しのラフ線、ネーム用紙のラフも）は下描きレイヤー・不透明度 50% で書き出します（ラフ線のレイヤーを分けたときは、レイヤーごとにその名前で、濃さはその割合をさらに掛けて）。CSP でその上に新しいレイヤーを作ってペン入れでき、塗りつぶしの参照や画像の書き出しには入りません（画面のチェック、`--no-draft-rough` で普通のレイヤーに）。

コマのメモとページのメモは、いちばん上の下描きレイヤー「メモ（ネーム）」に、アプリの画面と同じ札で書きます（ペン入れ中に見られ、印刷されない。付箋は書かない。画面のチェック、`--no-notes` で書かない）。

コマごとのフォルダー＋レイヤーマスク: 書き出し画面の「コマ」で選ぶか `--panel-masks` で、コマごとにフォルダー「コマ1」「コマ2」…（読む順）を作り、コマの形にレイヤーマスクを付けます。マスクはコマ（裁ち切りの辺はキャンバスの外まで）と、そこにかかるはみ出しの範囲で、上に重なるはめ込みのコマの下は隠します。コマのラフ線（点の多くがそのコマにある線）と空の「ペン入れ」レイヤーがフォルダーに入り、コマの外に出た線は切らずにマスクで隠すだけなので、CSP でマスクを描き足せば飛び出しになります。どのコマにもない線とはみ出しのラフ線、コマ枠の線はこれまでどおりフォルダーの外です。見開きページでは、見開きのコマの両半分を 1 つのフォルダーにします。見本のページは要りません（フォルダーとマスクの形式は docs/csp-layer-mask.md）。

コマ枠フォルダー（試験中）: 画面の「コマ」でコマ枠フォルダーを選ぶか `--frame-folders` で、コマを CSP のコマ枠フォルダー「コマ」の枠にし、その中に空の「ペン入れ」レイヤーを入れます（そこに描くとコマの外にはみ出しません）。枠線の太さはネームのとおり、裁ち切りの辺はキャンバスの外まで伸ばします。マスクと枠線の画像は CSP が開くときに枠から描きます（CSP 自身もそう保存します）。コマ枠フォルダーの設定は、コマ枠フォルダーを作って保存した CSP のページ（仕上げた原稿など）を見本のページに選ぶとそこから写します。点線・波線・枠なし・はめ込み・見開きの半分・はみ出しで切れるコマ・のど側の裁ち切りは、これまでどおり「コマ枠」ベクターレイヤーの線にします。

セリフだけ反映（ペン入れを始めたあとで台本を直したとき）: 書き出し画面の「セリフだけ反映…」か `--update-dialogue` で、前に書き出したフォルダーのページ（CSP で描き進めたもの）に、ネームで変わったセリフとフキダシだけを入れます。描いたレイヤーやほかのレイヤーはそのままです。
- 同じセリフのテキストレイヤーは触りません（CSP で動かした位置もそのまま）。変わった・消えたセリフは消さずに隠して名前の頭に「（旧）」を付け、新しいセリフをその上に足します（見比べてから CSP で消せます）
- フキダシ（「フキダシ」ベクターと「フキダシの塗り」）は、ネームで形が変わったページだけ同じように入れ替えます
- 「メモ（ネーム）」レイヤーは、ネームのメモが変わったページだけその場で描き直します（`--no-notes` で触らない）
- 書き出したときの中身を書き出し先の `.name-studio-export.json` に控えておき、CSP で直したセリフ（ネームでは変えていないもの）と CSP で足したテキストはそのままにします。フキダシを CSP でもネームでも直したときはネームのものにし、知らせます
- 変える前のページは書き出し先の `name-studio-backup/日時/` に写します。書き出したときと同じひな形・ページ数・見開きで反映してください。CSP でページを開いているときは、保存して閉じてから

CSP のセリフを読み戻す（ペン入れ中に CSP でセリフを直したとき）: 書き出し画面の「CSP のセリフを読み戻す…」か `--read-dialogue` で、前に書き出したフォルダーのページから、CSP で直した・足した・消したセリフをネームに入れます。ネームと CSP の両方で直さなくて済みます。
- 書き出したとき（反映したとき）の中身と比べて、CSP で変わったセリフだけを入れます。ネームで変えたところはそのままで、両方で変えたセリフはネームのものを残して知らせます
- 直したセリフは、似ている言葉か同じ場所のものを組にして書き換えます（縦書きの右上はそのまま）。足したセリフは CSP の位置に、そのコマのセリフとして入れます
- 入れる前に、変わったセリフを 1 件ずつチェックを付けて並べます（はじめは全部に付いています）。外したものはネームのままで、次の「セリフだけ反映」で CSP もネームに合わせます。元に戻すは Ctrl+Z。命令パレットの「CSP のセリフを読み戻す」からも、そのネームの前回の書き出し先で始められます。`--read-dialogue` はネームのファイルに保存します
- 読み戻したセリフは、次の「セリフだけ反映」でそのまま残ります（言葉に合わせてフキダシだけ入れ替わります）。書き出したときの記録がないページ（前のバージョンで書き出したもの）は読み戻しません

## 作業を失わないために

- 自動保存: 変更が止まって 3 秒後（続けて変えていても 30 秒ごと）に、ファイルか控えに書きます（秒数は設定の「保存」で変えられます）。中身が変わっていなければ書きません（何も変えない操作や、変えて元に戻しただけのときも、ファイルも版の履歴もそのまま）。版の履歴は 1 ネームあたり 300 MB まで（古い自動保存の版から消し、新しい保存の版 10 個は必ず残す）
- 保存できない細かい不整合（消した人物を指すセリフ、重なった id など）は、保存の前に直して何を直したかを出します（元に戻すで戻せます）。自動保存でそういう問題が見つかったときも控えには必ず残し、上に警告を出します
- 操作の途中で問題が起きたら、その操作を取り消して（ネームが中途半端な状態で残らない）上に知らせ、`%LOCALAPPDATA%\<アプリ>\logs\name-studio.log` に記録します
- 起動したとき、保存しないまま終わったネームがあれば、更新の確認より先に復元するか聞きます
- 保存はアプリが書いた中身をそのまま書くので、新しい版で足した項目が古い仕組みで消えることはありません。点の座標は 0.01 mm（筆圧などは 0.001）で保存します

## テスト

```bash
cargo test
(cd app && npm test)
# 画面の通しテスト（ブラウザで開く・描く・元に戻す・失敗の取り消し・自動保存・連続表示と速さ）
(cd app && npx playwright install chromium && npm run e2e)
# 実アプリで書き出す（WebView・CSP・Rust 側との通信まで。Linux は xvfb-run を前に付ける）
(cd app && npx tauri build --no-bundle)
cargo run -p clip-core --features fixtures --example fixture_page -- /tmp/app-check/page.clip
(cd app && node e2e/realapp.mjs /tmp/app-check)
# Python 版との突き合わせ（実ファイルを引数に足せる）
CSP_NAME_SPLITTER=../csp-name-splitter python tools/compare_with_python.py [作品のファイル...]
```

作品のファイルはリポジトリに入れません。テストは合成したファイルだけを使います。

ネームデータの型は Rust（`crates/name-model/src/model.rs`）と画面（`app/src/model.ts`）の 2 か所にあります。項目や選択肢を足すときは両方に足し、`app/src/contract.test.ts` の全項目の見本にも足して `(cd app && npx vitest run -u src/contract.test.ts)` で `crates/name-model/tests/fixtures` を書き直してください。片方に足し忘れると、型チェックか `cargo test`（`tests/contract.rs`）が落ちます。Rust 側にコマンドを足したら `app/src/backend.ts` の `Commands` にも書いてください（`backend.test.ts` が `lib.rs` と突き合わせます）。

画面側（`app/src`）のモジュールは、変わる速さで層に分けています（遅い順に 型・計算・仕組み・描画・書き出し・画面・起動）。どの層かは `app/src/architecture.test.ts` の `LAYERS` に書き、上の層から import すると落ちます。計算の層（ネームの操作）はブラウザ・保存場所・Rust 側に触らず、この PC に残す設定は `prefs.ts`（中身は `settings.ts`）、画像の読み込みは `pictures.ts`、キャンバスへの描画は `pagedraw.ts` を通します。ファイルを足したら `LAYERS` にも書いてください。
