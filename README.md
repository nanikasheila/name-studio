# name-studio

ネーム（漫画の絵コンテ）制作専用ツールです。CLIP STUDIO PAINT 本体には触らず、
.clip / .cmc ファイルの読み書きだけで CSP とつながります。ペン入れ以降は今までどおり CSP で行います。

構想と段階計画は [検討ドキュメント](https://claude.ai/artifact/PhzqeXUZhD9LZs2pbkRsLs) にあります。
ファイル形式の解析結果は csp-name-splitter の
[docs/formats/csp-file-format.md](https://github.com/nanikasheila/csp-name-splitter/blob/main/docs/formats/csp-file-format.md) を参照してください。

## できること

- CSP のネーム用紙（.clip）を開いて、全体表示と右綴じの見開き表示で見直す
- ページ枠（テンプレートの四角形）から 1〜N ページを自動で割り当てる
- レイヤーの表示切り替え、ページごとのセリフ一覧（縦書きで表示）
- ネーム用紙をページごとの .clip と作品ファイル（.cmc）に書き出す（レイヤーを保ったまま）
- ネームデータ（.namestudio）の編集。ネーム用紙から取り込むか、白紙から作る
  - ネーム用紙からの取り込み: 題名はその用紙をページに持つ作品（.cmc）の名前、なければ作品名と話数。余白の文字はセリフにせずページのメモに。後ろの空のページは除くか聞く
  - コマ割り: コマを横切る線で割る（間白つき、斜めも可）、囲んで新しいコマ、角をドラッグして形を変える（枠に吸い付く）
  - セリフ: クリックで置く、縦書き・種類（セリフ／モノローグ／ナレーション／描き文字）・話者・文字の大きさ。フキダシは文字に合わせて伸び縮み
  - ラフ: ペン（筆圧つき）と消しゴム。取り込んだネーム用紙のラフ画像を下に薄く表示
  - ページの追加・削除・並べ替え、ページのメモ、台本（全セリフを読み順に）、登場人物
  - 付箋（左の「付箋」）: 全ページの付箋を一覧に。押すとその付箋へ、決まったら「済み」で外す
  - 人物: 口調のメモ（セリフを選ぶと右の欄に出る）、数を押すとその人のセリフを並べて見比べ、押すとそのセリフへ
  - コマやセリフを選んでいる間も、右の欄の上にそのページのメモ（プロット）を出す
  - Markdown の台本の取り込み（左の「台本」）: ページ・コマ・セリフ・ト書き。長いセリフは自動で改行して台本のコマの中に置く（文の切れ目「。！？」では必ず改行、細いコマでは細く・少し小さく）。`### 5ページ` のようにページ番号があれば、そのページから入れる。台本を直して取り込み直すと、セリフのあるページは台本に合わせて直す（変わったセリフだけ書き換え・足す・消す。位置・形・しっぽはそのまま。足したセリフはラフの顔とほかのフキダシをよけて置く。取り込む前に件数を出す。コマのメモの書き換えも数える）。アプリが書き出した台本（■ / ［N］）を直して取り込み直しても同じで、セリフ中の全角スペースは改行として読む。ページはセリフの似ている度合いで突き合わせるので、台本でページを足すとその位置にページを入れ、後ろのページはずれない（台本から消したページはそのまま残して知らせる）。フキダシを動かして読む順が変わっていても、似ているセリフ同士を組にする。`### 1ページ 副題` の副題はページのメモに。`名前〔電話〕「…」`（電話・無線 → 電子音、叫び → トゲ、小声 → 破線、独白 → モノローグ）、`「…！！」` はトゲ
  - 元に戻す・やり直す（Ctrl+Z / Ctrl+Shift+Z）、保存（Ctrl+S）
  - 書き出し（「書き出す…」）
    - CSP のページ: ページごとの .clip（ラフ線・コマ枠・フキダシ・セリフ・取り込んだラフ画像を別レイヤー）と作品ファイル（.cmc）。ネームの基本枠をひな形の基本枠に合わせる
    - 書き出す前の確認: フキダシの重なり・コマの外のセリフ・コマからはみ出したセリフ・仕上がりの外・しっぽのないセリフ・ラフの顔にかかるセリフを一覧にし、押すとそのセリフへ。はみ出しは「はみ出したセリフのコマを並べ直す」でまとめて改行し直す。顔にかかるセリフは「顔にかかるセリフをずらす」で、そのセリフだけ顔とほかのフキダシをよけてずらす（よけきれないコマは並べ直す）
    - PDF: 全ページを 1 つの PDF に（右綴じで開く指定つき）
    - 台本: ページ・コマ・話者つきのテキスト
  - 全体を見る画面（F1〜F4、F6 で切り替え）
    - 全体（F6）: 話の型・シーン・時系列・感情曲線・字数・ページとコマを同じページの並びで一画面に重ね、その場で直す。区切りやシーンの端・時系列の棒・感情の線をドラッグ、ページ番号の帯でページを移動、コマを別のページのコマへドラッグで中身（絵・セリフ・塗り・メモ）を入れ替え。クリックで右の欄にシーン・ページ・コマの中身（あらすじ、メモ、感情の値、セリフ）。Ctrl＋ホイールか「幅」で拡大縮小
    - 話の型: 起承転結・三幕構成・序破急・Save the Cat（ビート付き）と、自分の型（区切りの名前・配分・色・ビートを決める。このネームとこの PC に保存され、ほかのネームでも選べる）。ページ一覧は型の区切りで色分け
    - プロットの取り込み（「台本」タブか全体の「プロット取り込み…」）: Markdown のプロット（### 1ページ 見出し＋本文、ページ配分の表、論点などの節）をページのメモ・シーン・付箋・目標ページ数に振り分ける。ページを書いていない論点の付箋は、中身の近いページ（見出しと本文の言葉で選ぶ）へ、重ならないように並べる（見開きで隠れないよう、ページの外側＝右ページは右端・左ページは左端に）。台本（#### コマとセリフ）か、プロットかは中身を見て決める。プロットのあとに台本を取り込むと、重なるシーンは台本のシーンに置き換わる（同じページ範囲なら要約を引き継ぐ）
    - 感情曲線は値のないページをまたぐところを点線に。「話すページに点」でその人物が話すページに、前後の値の間をとって点を打つ
    - 新しいネームは作品名・ページ数・目標ページ数・話の型を聞いてから作る
    - 構成: シーン（ページの範囲・物語の中の時・時系列の順・あらすじ）の表、ページごとの字数、ページ一覧
    - 感情曲線: 登場人物ごとの気持ちの上下（-1〜1）を図に直接クリックして入れ、メモを付ける
    - 時系列: ページの順と物語の時間の順を見比べる（回想が分かる）
  - 道具の切り替え: V 選択、K コマ割り、T セリフ、P ペン、E 消しゴム、G 塗り。Space＋ドラッグで移動、ホイールで拡大縮小、Shift＋Space＋ドラッグ（または - と ^）で画面を回す、Ctrl+0 で全体表示、Tab で左右の欄を隠す。キーは「キー…」で変えられる
  - コマの変形: 選択ツールでコマの境目（間白）をドラッグすると両側のコマが一緒に動く。外側の辺は辺だけ動く。境目をダブルクリックで隣のコマとつなげる
  - その場で書く: コマをダブルクリックでコマのメモ（ページの上に札で出る。書き出しには入らない）、セリフをダブルクリックかセリフツールでクリックで文字を直接
  - 選んだもののそばに操作バー。選んだラフ線とセリフは枠で拡大縮小・回転、左右反転。Ctrl+C / X / V でコピー・切り取り・貼り付け（ポインターのあるページへ）、Ctrl+A でページのもの（コマ・線・セリフ・塗り・はみ出し）を全部選ぶ
  - ペンで Shift を押しながら引くと直線。塗りツールで囲んだ所をベタ・グレー・白で塗る
  - 変形（Ctrl+T か操作バーの「変形」）: コマ・フキダシ・塗り・はみ出しを拡大縮小・回転、Ctrl + 角で自由変形。コマは中に描いたものと一緒に
  - セリフを直す: 右の欄でもその場の書き込みでも、縦書きは右上（読み始め）を動かさずにフキダシが左下へ伸びる（しっぽの先はそのまま）。改行せずに打った長いセリフは、決定したときに句読点や助詞のあとで改行する
  - セリフを並べる: コマの操作バーの「セリフを並べる」、ページの「このページのセリフを並べ直す」で、読む順に右上から並べ直す（長いセリフは句読点や助詞のあとで改行。裁ち切りのコマでも基本枠の内側に。斜めのコマで細い端からはみ出すときは、収まるところまで寄せる。ラフに描いた人物の顔（頭のあたり）には重ねず、左か下へよける。アプリが改行したセリフは、改行を変えればよけられるときは改行し直す（手で改行したセリフはそのまま）。よけきれないときは重なりが一番少ないところへ）
  - 重なったセリフ: 同じ所をもう一度クリックすると下のセリフを選ぶ
  - 見開き: 左右どちらのページでも、クリックしたページが右の欄に出る
  - コマ割りの型を当てても、コマの中身（ラフ線・セリフ・塗り・メモ）は読む順に新しいコマへ移る（余った分は最後のコマに）
  - 型はコマ数を指定して当てられる（型の見た目のまま、段のコマをつなげる・割って合わせる）。台本の取り込みでも、選んだ型を台本のコマ数に合わせて作る。台本に `型：導入` と書いたページはその型
  - コマのメモ・ページのメモ・付箋は仕上がりの中に収まるように出る（コマのメモはフキダシを避けて角に）
  - フキダシの形を「〇〇の既定にする」と、その作品でその種類のセリフを作るときの形になる（独白は多角形、など）
  - まとめて選ぶ: Shift + クリックで足す・外す、Shift + ドラッグ（または何もない所からドラッグ）で囲んだものを選ぶ。選んだコマ・線・セリフ・塗り・はみ出しをまとめて動かす・拡大縮小・回転・自由変形・コピー・削除（コマは中に描いたものと一緒に）
  - しっぽを付ける: ページの欄か書き出す前の確認から、しっぽのないセリフ全部に。コマのラフの人物（線のかたまり）の頭へ向け、先に話す人ほど右の人物に。同じ話者は同じ向き。ラフがなければコマの下へ
  - しっぽ: どのしっぽも直接つかめる（途中をつかんで振る、ひし形で曲げる）。Alt + フキダシからドラッグで足し、先をフキダシに戻すと消える
  - レイヤー（左の欄）: 見開きのコマごとに中のセリフ・ラフ線・塗り（CSP のコマ枠フォルダのように）。行で選ぶ、目で画面から隠す、行をコマへドラッグで移す
  - ペンとタブレット（「ペン…」）: 筆圧カーブ（描いて調節も）、傾き、消しゴム側、サイドボタン、指（1 本指で移動、2 本指で拡大縮小・回転、タップで元に戻す・やり直す、手のひらを無視）、カーソル

## 構成

| 場所 | 中身 |
| --- | --- |
| `crates/clip-core` | .clip / .cmc の読み取り（レイヤーツリー、ラスター画素、ベクター、テキスト、ページ枠、ページ一覧） |
| `crates/name-model` | ネームデータ（正本、.namestudio）。ページ・コマ・セリフ・ラフ線・シーン・登場人物・感情の値 |
| `crates/name-cli` | コマンドライン（`inspect` / `cells` / `import` / `split` / `decode-time`） |
| `app/` | 画面（Tauri 2 + TypeScript）。`app/src-tauri` が Rust 側 |
| `tools/compare_with_python.py` | Python 版（csp-name-splitter の `name_splitter/csp`）と出力を突き合わせる |

Rust 版は Python 版の移植で、Python 版を正解として同じ結果になることを確かめながら進めます。

## 使い方

Windows のインストーラーは GitHub Actions の「Release Windows app」が main ごとにリリースとして公開します（入れたアプリは自動で更新されます）。
署名していないため、初回は SmartScreen の警告が出ます。

開発する場合:

```bash
cd app
npm install
npm run tauri dev      # 画面を起動
npm run tauri build    # インストーラーを作る
```

コマンドライン:

```bash
cargo build --release -p name-cli
./target/release/name-studio-cli inspect page0001.clip --pixels
./target/release/name-studio-cli cells ネーム.clip
```

`inspect` の出力は Python 版の `csp-name-splitter inspect` と同じ JSON です。

アプリ自体も、画面を操作せずにネームを CSP へ書き出せます（書き出し画面と同じ処理。
終わると結果の JSON を書いて閉じ、読み直しで問題がなければ終了コード 0）:

```bash
name-studio-app --export-csp ネーム.namestudio --template page.clip --out 書き出し先 \
  [--work-template 作品.cmc --work-name 第1話] [--story-index 1] [--donor 見本.clip] [--no-draft-rough] [--no-notes] [--frame-folders] [--update-dialogue] [--report 結果.json]
```

線とセリフを CSP で直せるベクター・テキストのレイヤーにするには、CSP がそのレイヤーを作った .clip が要ります。
ひな形、`--donor`（書き出し画面の「見本のページ」）、取り込み元のネーム用紙、ひな形と同じフォルダーのページの順に探し、
見つからない部分は画像レイヤーになります（画面では書き出す前に聞き、結果の JSON では `summary` の先頭に「注意」を書きます）。

ラフ線（はみ出しのラフ線、ネーム用紙のラフも）は下描きレイヤー・不透明度 50% で書き出します。CSP でその上に新しいレイヤーを作ってペン入れでき、塗りつぶしの参照や画像の書き出しには入りません（画面のチェック、`--no-draft-rough` で普通のレイヤーに）。

コマのメモとページのメモは、いちばん上の下描きレイヤー「メモ（ネーム）」に、アプリの画面と同じ札で書きます（ペン入れ中に見られ、印刷されない。付箋は書かない。画面のチェック、`--no-notes` で書かない）。

コマ枠フォルダー（試験中）: 画面の「コマ枠をコマ枠フォルダーにする」か `--frame-folders` で、コマを CSP のコマ枠フォルダー「コマ」の枠にし、その中に空の「ペン入れ」レイヤーを入れます（そこに描くとコマの外にはみ出しません）。枠線の太さはネームのとおり、裁ち切りの辺はキャンバスの外まで伸ばします。マスクと枠線の画像は CSP が開くときに枠から描きます（CSP 自身もそう保存します）。コマ枠フォルダーの設定は、コマ枠フォルダーを作って保存した CSP のページ（仕上げた原稿など）を見本のページに選ぶとそこから写します。点線・波線・枠なし・はめ込み・見開きの半分・はみ出しで切れるコマ・のど側の裁ち切りは、これまでどおり「コマ枠」ベクターレイヤーの線にします。

セリフだけ反映（ペン入れを始めたあとで台本を直したとき）: 書き出し画面の「セリフだけ反映…」か `--update-dialogue` で、前に書き出したフォルダーのページ（CSP で描き進めたもの）に、ネームで変わったセリフとフキダシだけを入れます。描いたレイヤーやほかのレイヤーはそのままです。
- 同じセリフのテキストレイヤーは触りません（CSP で動かした位置もそのまま）。変わった・消えたセリフは消さずに隠して名前の頭に「（旧）」を付け、新しいセリフをその上に足します（見比べてから CSP で消せます）
- フキダシ（「フキダシ」ベクターと「フキダシの塗り」）は、ネームで形が変わったページだけ同じように入れ替えます
- 「メモ（ネーム）」レイヤーは、ネームのメモが変わったページだけその場で描き直します（`--no-notes` で触らない）
- 書き出したときの中身を書き出し先の `.name-studio-export.json` に控えておき、CSP で直したセリフ（ネームでは変えていないもの）と CSP で足したテキストはそのままにします。フキダシを CSP でもネームでも直したときはネームのものにし、知らせます
- 変える前のページは書き出し先の `name-studio-backup/日時/` に写します。書き出したときと同じひな形・ページ数・見開きで反映してください。CSP でページを開いているときは、保存して閉じてから

CSP のセリフを読み戻す（ペン入れ中に CSP でセリフを直したとき）: 書き出し画面の「CSP のセリフを読み戻す…」か `--read-dialogue` で、前に書き出したフォルダーのページから、CSP で直した・足した・消したセリフをネームに入れます。ネームと CSP の両方で直さなくて済みます。
- 書き出したとき（反映したとき）の中身と比べて、CSP で変わったセリフだけを入れます。ネームで変えたところはそのままで、両方で変えたセリフはネームのものを残して知らせます
- 直したセリフは、似ている言葉か同じ場所のものを組にして書き換えます（縦書きの右上はそのまま）。足したセリフは CSP の位置に、そのコマのセリフとして入れます
- 入れる前に件数と中身を出します。元に戻すは Ctrl+Z。`--read-dialogue` はネームのファイルに保存します
- 読み戻したセリフは、次の「セリフだけ反映」でそのまま残ります（言葉に合わせてフキダシだけ入れ替わります）。書き出したときの記録がないページ（前のバージョンで書き出したもの）は読み戻しません

## テスト

```bash
cargo test
(cd app && npm test)
# Python 版との突き合わせ（実ファイルを引数に足せる）
CSP_NAME_SPLITTER=../csp-name-splitter python tools/compare_with_python.py [作品のファイル...]
```

作品のファイルはリポジトリに入れません。テストは合成したファイルだけを使います。
