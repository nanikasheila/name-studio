# CSP のフォルダーとレイヤーマスク（Name Studio での使い方）

フォルダーの行とレイヤーマスクの形式そのものは、
[csp-format の仕様 03 章「マスク」](https://github.com/nanikasheila/csp-format/blob/main/docs/spec/03-canvas-and-layers.md)が正本です
（どの列のどのビットが立つか、マスクのオフスクリーンの形）。形式について新しく分かったことは、そちらに書いてください。

ここには、書き出しの「コマごとのフォルダー＋レイヤーマスク」（`--panel-masks`）がそれをどう使うかだけを書きます。

## 何を作るか

- コマごとにフォルダー「コマ1」「コマ2」…（読む順）を作り、コマの形のレイヤーマスクを付けて、マスクを有効にする（`clip-core` の `write::layers::set_layer_mask`）。
- マスクは、コマ（裁ち切りの辺はキャンバスの外まで）と、そこにかかるはみ出しの範囲。上に重なるはめ込みのコマの下は隠す。
- マスクのミップマップとサムネイルは、フォルダー自身の描画用のものを写して作り、各段に 1 面（8 bit）の画素を書く。
  オフセット（`LayerMaskOffsetX/Y` など）は 0。
- フォルダーの中には、そのコマのラフ線と空の「ペン入れ」レイヤーを入れる。コマの外に出た線は切らずに、マスクで隠すだけ。

## なぜクリッピングではなくマスクか

CSP で作った見本にはもう一つの形がありました。フォルダーの中で、コマの形に塗ったラスター「コマ塗り」の上に、`LayerClip = 1` のフォルダーを置く形（下のレイヤーでクリッピング）です。
書き出しはレイヤーマスクの方を使います。中に足したレイヤーもすべて隠れ、紙の白を塗らずに済むからです。
CSP でマスクを描き足せば、そこだけ飛び出しになります。

## 確かめ方

見本は CSP EX 5.1.4 で作ったもの（クリッピングとレイヤーマスクの両方の例）と仕上げ原稿のページで、書いたページを CSP で開いて、
コマの外が隠れること、マスクを消すと線が出ることを確かめました（2026-10-25）。
