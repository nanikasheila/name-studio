# Name Studio の使い方（くわしい説明）

[README](../README.md) では作業の流れを、ここでは機能ごとにできることを詳しく書いています。
迷ったときはアプリの中で Ctrl+K（命令パレット）か右上の ? を押すと、その場で探せます。

## ネームを始める

- ネーム用紙からの取り込み: 題名はその用紙をページに持つ作品（.cmc）の名前、なければ作品名と話数。余白の文字はセリフにせずページのメモに。後ろの空のページは除くか聞く
- 開始画面: 最近開いた・保存したネームを新しい順に並べ、ワンクリックで開き直せる（ページ数といつ開いたかも出る。× で一覧から外す。開けなかったもの（移した・外付けのドライブがつながっていないなど）は一覧に残り、理由と「もう一度」「場所を探す…」「一覧から外す」が出る。場所を探して開けたら、一覧は新しい場所に）。開始画面でも Ctrl+K で「開く」「新しいネーム」と最近のネームを名前で探せる
- 見本で試す（開始画面）: 8 ページの見本のネーム（コマ・セリフ・しっぽ・ラフ・人物・シーン・付箋入り）を開き、その上で「使い方の案内」を最初から出す。保存するまでファイルにはならないので、描き足しても消しても構わない（Ctrl+S で好きな場所に保存もできる）
- 新しいネームは作品名・ページ数・目標ページ数・話の型を聞いてから作る
- ネーム画像の取り込み（上の「取り込む…」、開始画面の「ネーム画像から…」）: 全ページを 1 枚にまとめたネーム画像（ミニネーム、CSP で書き出したネーム用紙、紙に描いてスキャンしたもの）から、ページの枠を見つけてページに分け、読む順に各ページへ置く。くっついて並んだページも境目の線とページの形で分け、ページの中の枠（ネーム用紙の基本枠）が見つかればそれをネームの基本枠に合わせる（仕上がり・キャンバスに合わせることもできる）。少し傾いたスキャンはまっすぐに直してから切る。うまく見つからないときは「段 × 列の格子で分ける」。読む順（段ごと・半分ずつ、右から・左から）を選べ、プレビューで押したページは外す。開いているネームでは何ページ目から入れるかを選び、足りないページは足す（1 回の Ctrl+Z で戻る）。置いた画像は資料画像の一種「ネーム画像」で、その上にコマ・セリフ・ラフを足していける。読む表示・PDF・ミニネームには少し濃く入り、CSP へは下描きレイヤー「ネーム画像」で出る。取り込み直すと前のネーム画像だけ置き換える
- Markdown の台本の取り込み（左の「台本」）: ページ・コマ・セリフ・ト書き。長いセリフは自動で改行して台本のコマの中に置く（文の切れ目「。！？」では必ず改行、細いコマでは細く・少し小さく）。`### 5ページ` のようにページ番号があれば、そのページから入れる。台本を直して取り込み直すと、セリフのあるページは台本に合わせて直す（変わったセリフだけ書き換え・足す・消す。位置・形・しっぽはそのまま。足したセリフはラフの顔とほかのフキダシをよけて置く。取り込む前に件数を出す。コマのメモの書き換えも数える）。アプリが書き出した台本（■ / ［N］）を直して取り込み直しても同じで、セリフ中の全角スペースは改行として読む。ページはセリフの似ている度合いで突き合わせるので、台本でページを足すとその位置にページを入れ、後ろのページはずれない（台本から消したページはそのまま残して知らせる）。フキダシを動かして読む順が変わっていても、似ているセリフ同士を組にする。`### 1ページ 副題` の副題はページのメモに。`名前〔電話〕「…」`（電話・無線 → 電子音、叫び → トゲ、小声 → 破線、独白 → モノローグ）、`「…！！」` はトゲ
- 左綴じ（海外コミック・横書き）: 新しいネームを作るときか「設定」の「読む向き」で選ぶ。見開きの左右（1 ページ目は右ページ）、コマとセリフの番号（左上から）、コマ割りの型（左右反転）、セリフの並べ直し・しっぽ・台本から作るコマとセリフ（左から右へ）、新しいセリフの横書き、← → キーとページ送りの向き、PDF の開き方が変わる。途中で切り替えると番号を振り直し、そろえる指定でセリフの縦書き・横書きも入れ替える（元に戻せる）。CSP の作品の綴じ方は作品のひな形に従うので、左綴じの作品をひな形にする
- 縦スクロール（Webtoon）: 新しいネームを作るときに「読む向き」で選ぶ。縦に続く帯を幅 120 × 高さ 240 mm（スマホ 2 画面ほど）の区切りに分けて描き、区切りが 1 ページになる（見開きなし、コマ番号は上から、セリフは横書き、コマ間の上下は広め 24 mm）。「連続」では区切りがすき間なく縦につながった帯になり、ホイールで上下、Ctrl＋ホイール（ピンチ）で拡大縮小、つまみで帯を何列かに分けて俯瞰できる。線は区切りをまたいで描ける。CSP には区切りごとのページで、PDF は 1 列に続けて開く指定で書き出す
- シリーズ（「シリーズ」の欄）: 何話ものネームで人物・ブラシ・フォント・作品の既定・CSP のページ設定・ラフ線のレイヤーを共有する。「シリーズを作る」でいまのネームを第 1 話にしてシリーズのファイル（`.nameseries`）を作り、「次の話を作る」で同じ設定の白紙の次の話を作る（ページ数は横の欄で決める。はじめはいまの話の目標ページ数、なければページ数。次の話の目標ページ数にもなる）。保存するとシリーズにも入り、ほかの話を開くとシリーズに合わせる（その話だけの人物も、セリフで使っていれば残る）。一覧の話を押すとその話を開く。すでにあるシリーズへは「シリーズに入れる」、外すのは「シリーズから外す」。ネームもシリーズの写しを持つので、シリーズのファイルがなくても開ける

## 画面

- 一画面: 編集しながら全体が見える。画面の切り替えはなく、ページの下に「物語の帯」、右の欄に選んだものが出る
  - 物語の帯: 話の型・シーン・時系列・感情曲線・字数・ページとコマを、同じページの並びに重ねて出す。はじめはシーンとページだけで、ページに窓の高さの 7 割ほどを残す（描く配置。それより低い窓、例えば高さ 900 px では、たたんで始める。帯のボタンはページのすぐ下の段の右にあり、F2〜F4 で段を足す、F6 で大きく、Shift+F6 でたたむ・広げる。自分で開いた・たたんだ・高さを変えたときはそれを覚える）。いま開いている見開きに枠が付き、ページやコマを押すとそこを上に開く。区切りやシーンの端・時系列の棒・感情の線をドラッグ、ページ番号の帯でページを移動、コマを別のページのコマへドラッグで中身（絵・セリフ・塗り・メモ）を入れ替え。帯の上の段のアイコンで出すレーンを選ぶ（F2 シーンと字数、F3 感情、F4 時系列）。上端のドラッグで高さ、F6（か上端のダブルクリック）で大きく・戻す（F1 で元の高さ）。Ctrl＋ホイールで拡大縮小、ホイールで横へ。ページの並ぶ向きは設定 › 表示の「下の帯のページの並び」で、左から右（初期）か、編集画面と同じ（右綴じは 1 ページ目が右端で右から左。左綴じ・縦スクロールは左から右）を選べる
  - 右の欄: 帯でシーンを押すと名前・物語の中の時・あらすじ・ページ・人物ごとの感情の線、「型」を押すと話の型・目標ページ数・区切り・ビート。何も選んでいないときのページの欄に、そのページの型の区切り・シーン（押すとシーンの欄へ）と感情の値・メモ
  - 話の型: 起承転結・三幕構成・序破急・Save the Cat（ビート付き）と、自分の型（区切りの名前・配分・色・ビートを決める。このネームとこの PC に保存され、ほかのネームでも選べる）。ページ一覧と帯のページは型の区切りで色分け
  - プロットの取り込み（「台本」タブ）: Markdown のプロット（### 1ページ 見出し＋本文、ページ配分の表、論点などの節）をページのメモ・シーン・付箋・目標ページ数に振り分け、帯を大きくして見せる。ページを書いていない論点の付箋は、中身の近いページ（見出しと本文の言葉で選ぶ）へ、重ならないように並べる（見開きで隠れないよう、ページの外側＝右ページは右端・左ページは左端に）。題名の末尾の「ページ配分付きプロット」「場面プロット」のような資料の種類は題名に入れない。場面やその最初のページが「現在。」「回想。」「翌朝。」のような時の言葉で始まるときは、それをシーンの時にし、シーン名は次の文から取る。台本（#### コマとセリフ）か、プロットかは中身を見て決める。プロットのあとに台本を取り込むと、重なるシーンは台本のシーンに置き換わる（同じページ範囲なら要約を引き継ぐ）
  - 感情曲線は値のないページをまたぐところを点線に。帯の人物の丸で、なぞる人物を選ぶ。「話す所に点」でその人物が話すページに、前後の値の間をとって点を打つ
- 画面の配置: 道具は左の縦の列、その道具の設定（ペンの種類・太さ・消し方・塗りの色）はページの上の 1 段、ページ送りと見開き／単独・コマのメモはページのすぐ下の段、その下に物語の帯。欄（サブツール・ツールプロパティ・ブラシサイズ・ページ・台本・人物・付箋・保留・レイヤー・詳細）は CSP のパレットのように左右どちらの列にも置け、いくつでも同時に上下に並べて開ける。窓の端に縦に並ぶアイコンで出す・隠す、見出しのダブルクリックでたたむ、間の線のドラッグで高さ（ダブルクリックで中身に合わせる）、列の内側の端のドラッグでその列の幅、「‹」で片側ごとアイコンだけに。**片側を 3 列まで分けられる**: 見出しを列の端（左右の縁）までドラッグして離すと新しい列になる（青い縦線が出る）。ほかの欄の見出しの上で離すとその欄の**タブ**になり（タブを押して前に出す、タブのドラッグで外へ）、ページの上で離すと**浮かせて**紙面の上に置ける（見出しのドラッグで動かし、右下の角で大きさ、列の上で離すと列に戻る）。同じことは見出しの「≡」（か見出しの右クリック）からもできる: たたむ・高さを中身に合わせる／列に合わせて分ける・新しい列を作って移す・反対側の欄へ移す・タブから外す・浮かせる／欄に戻す・隠す。サブツールとツールプロパティは中身の高さだけ取り、残りをほかの欄が分け合う。何も出ていない列はなくなる。並びは次に開いたときも同じ。道具を変えてもほかのボタンは動かない。右の欄は選んだもの（コマ・セリフ・付箋など）の色とアイコンで、長い説明は「?」で開く。ページ一覧はコマ割りの図（セリフが多いコマほど濃い）
- 単独ページ表示: 下の帯の「単独」で 1 ページずつ大きく（見開きに戻すのは「見開き」）
- 連続（一枚のキャンバス）: ページの下の段の「連続」（F7）で、紙のネームのように全ページを一枚に並べる。見開きごとに読む順（右綴じは右から左）、行は上から下。行数はつまみ（Alt+↑ / Alt+↓）でなめらかに変わり、1 行なら全ページが横一列に、増やすほど格子になって俯瞰しやすい。いま描いている見開きは画面の同じ場所に残る。どのページにもそのまま描け、ペンの線はページやノドをまたぐとそれぞれのページに分かれる。セリフ・ラフ線・コマ（中身ごと）は別のページへドラッグで移る（動かしている間はページの間や移る先のページの上にも見え、移る先のページに枠と「N ページへ」が出る）。ホイールで拡大縮小（ポインタの下のページは動かない）、Shift＋ホイールで行に沿って、Ctrl+Alt+0 で全ページを画面に、Ctrl+0 でいまの見開きを大きく。触ったページの見開きが右の欄と帯の枠になる。小さく見ているときはコマ番号やメモを出さず絵だけにする
- 読む（F5）: ページの下の段の本のボタンか F5 で、ネームを窓いっぱいの見開きで通し読みする。付箋・メモ・コマ番号・選択・枠は出さず、読者や編集者が見るままに。← → で読む向きにめくり（右綴じは ← が次）、クリック・タップは読む先の側（右綴じは左半分）で次へ、スワイプやホイールでもめくる。Home / End で最初・最後、Esc（または F5）で最後に読んでいた見開きのまま編集に戻る
- コマやセリフを選んでいる間も、右の欄の上にそのページのメモ（プロット）を出す
- ページの番号とメモはページの下に全文を出す（ページの幅で折り返し、行頭に「。」「、」などが来ないように）。長いメモがあると、その分ページの下の間が広がる（見開き・単独はどの見開きでもページの大きさが変わらないよう、いちばん長いメモに合わせる。連続は行ごとに、その行のいちばん長いメモに合わせる）
- 見開き: 左右どちらのページでも、クリックしたページが右の欄に出る
- 設定（上の「設定」）: 左の一覧で分類を選ぶか、上の欄で探す（例: 太さ）。このネーム（ファイルに保存）: コマ割り（コマ間、枠線・太枠の太さ）、セリフ・フキダシ（種類ごとの文字の大きさとフキダシの形の既定、フキダシの線の太さ）、フォント（用途ごと）、読む向き。この PC: 画面の見た目（配色、画面のフォントと文字の大きさ、カスタム CSS）、表示（「連続」のページの間隔、コマのメモ、ヘルプの帯）、操作（コマと中身を一緒に動かす、フキダシの変形で文字の大きさも変える）、吸着、保存（自動で上書き保存）、ペン・キー。「新しいネームの既定にする」で、このネームの設定をこれから作るネームにも使う。1 つのコマの枠線の太さ・1 つのセリフのフォントは右の欄で、文字の大きさとコマの太さは右の欄の「既定にする」でも決められる
- 画面の見た目（設定 › 画面の見た目、この PC）: アプリの画面だけを変える（ページの白・描いたもの・書き出しは変わらない）。配色は Windows に合わせる（初期。Windows の明るい・暗いに合わせて切り替わる）・明るい・暗い・目にやさしい（生成りの地に茶の文字）・高コントラスト（黒地に白と黄色／白地に黒と濃い青。選んでいるところに太い枠）から、それぞれの配色の見本を押して選ぶ。画面のフォント（メニュー・ボタン・欄の文字。一覧はその書体で出る。× でアプリの既定の Yu Gothic UI）と文字の大きさ（11〜20 px、初期 14。道具の列は名前が収まるよう広がる）。カスタム CSS: 「カスタム CSS を使う」の欄に CSS を書くか「ファイルから読み込む…」で .css を読み、「当てて試す」で画面に当てる。15 秒のあいだ試していて、下の帯の「このままにする」を押すと次の起動からも使い、押さなければ（「元に戻す」でも）元に戻る（試した CSS は欄に残るので直してもう一度試せる）。かっこの数が合わないところと @import（読み込まない）は当てる前に欄の下に出る。画面の色は CSS 変数にまとまっている（`--bg` 窓の地、`--panel` 欄・ボタン、`--line` 線、`--text` 文字、`--muted` 控えめな文字、`--accent` 選んでいるもの、`--on-accent` その上の文字、`--stage` ページのまわり、注意の `--warn-*`・失敗の `--error-*`、道具ごとの色 `--c-panel`・`--c-line`… など）。「今の色をひな形に入れる」で、いまの配色の値と説明つきの一覧が欄に入る（`:root, [data-theme] { … }` に書くと、どの配色にも効く）。画面が崩れて戻せないときは Ctrl+Shift+Alt+R（キー設定では変えられない決まったキー）で配色・フォント・大きさを初期に戻し、カスタム CSS を切る（中身は残る）。キーも効かないときは Shift を押しながら起動する（または `--safe-look` を付けて起動）と、その回はカスタム CSS を当てない。「この PC の設定を初期に戻す」でも見た目は初期に戻る 「ボタンや入力欄を大きめにする」で、押すところが 28px 以上になり、文字が 1 段（2px）大きくなる（ペンタブレットや細かい画面向け）。はじめてペンで触ったとき、または横 2560 ピクセル以上の画面を 150% 未満の表示で使っているとき、この PC で 1 回だけ「大きめにする」を勧める知らせが出る（押すとその場で大きめになる。× で閉じれば、そのまま）。
- 使われ方（設定 › この PC › 使われ方）: よく使う命令（キー・命令パレット・ボタン）・道具・書き出しの回数と、使った日数を、この PC の中だけで数えて見せる（どこにも送らない）。キー設定や作業の配置を決める手がかりに。「テキストでコピー」で人に見せられる形にコピー、「数えたものを消す…」で全部消す。チェックを外すと数えない
- 作業の配置（上の「描く・全体・CSP」、Ctrl+1・Ctrl+2・Ctrl+3）: 欄・ページの見せ方・物語の帯を用途に合わせてまとめて切り替える（CSP のワークスペースのように）。「描く」はサブツール・ツールプロパティとレイヤーだけで右の列はアイコンに、帯はたたむ。「全体」は連続で全ページを画面に収め、ページ・台本・付箋と帯を出す。「CSP」は書き出す前に、ページ・付箋（未決）・保留とレイヤー・詳細を出す。配置の中で動かした欄・見せ方は、その配置に覚える（はじめは今までの並びが「描く」）。命令パレットの「今の配置を既定に戻す」で出荷時の並びに。**名前をつけた配置**（CSP のワークスペースの登録のように）: 左の端のアイコンのいちばん下（配置のアイコン）から「今の配置に名前をつけて残す…」で、いまの欄の並び（列・タブ・浮かせた欄も）・見せ方・物語の帯を名前をつけて残し、そのメニューの一覧からいつでもその配置に戻る（使っている間はアイコンに色が付き、動かした欄はその配置に覚える。「上書き」で今の画面のとおりに残し直す）。「名前をつけた配置の整理…」で名前の変更・並べ替え・削除（12 まで）
- ヘルプ: 窓の下の「ヘルプの帯」に、ポインターの下にあるもの（道具・ボタン・コマ・セリフ・しっぽ・コマの境目・変形の枠・物語の帯の行など）の名前と、マウス・キーでできること（「ドラッグ 動かす」「ダブルクリック コマのメモを書く」「Ctrl+T 変形」）が出る。キーは「キー設定」で割り当てたまま、Shift・Alt・Ctrl・Space を押すとそれを使う操作が先に出る。帯の × か「設定 › 表示」で隠せる。? か右上の ? ボタンで「画面のヘルプ」（各部に名前と使い方とキーを重ねて出す。クリック・?・Esc で閉じる）。はじめて使うときは開始画面と編集画面で「使い方の案内」が順に各部を示す（→・Enter で次、← で前、Esc で閉じる。画面のヘルプ・設定・命令パレットからもう一度見られる）
- 命令パレット（Ctrl+K）: 命令の名前を少し打つと探せて、Enter で実行。キーも横に出る。コマ割りの作り方（割る・四角・多角形）・保留・読み戻し・次の話・読む表示も命令になっていて、「キー設定」でキーを割り当てられる。ひらがな・カタカナ・全角の違いは気にしなくてよく、最近使った命令が先に出る。いま使えない命令は薄く出る

## コマ割り

- コマ割り: コマを横切る線で割る（間白つき、斜めも可）、囲んで新しいコマ、角をドラッグして形を変える（枠に吸い付く）
- コマを足す: コマ割り道具の段で「割る」（横切るように引いて割る。Shift＋コマの外のドラッグで四角いコマ）・「四角」（ドラッグで四角いコマ）・「多角形」（クリックで角を置き、最初の角・ダブルクリック・Enter で閉じる。Backspace で 1 つ戻す、Esc でやめる）。コマの中に描いたコマは、はめ込み（白で上に重なる）
- コマの変形: 選択ツールでコマの境目（間白）をドラッグすると両側のコマが一緒に動く。外側の辺は辺だけ動く。境目をダブルクリックで隣のコマとつなげる。選んだコマの角をドラッグで形を変える（台形など）
- 吸着: コマの移動・角・辺・拡大縮小とコマを描くとき、隣の角と水平・垂直、ほかのコマの辺の線とその外側のコマ間ぶん、基本枠・裁ち切り線・用紙の端、グリッドに吸い付く。吸い付いた線はピンクの点線で出る。Alt を押している間は吸着しない。どれに吸い付くか・グリッドの間隔は「設定」で、グリッドの入り切りはコマ割り道具の段でも
- 決めきらないコマ割り（仮のコマ）: コマ割り道具の段の「描く」で、紙のようになぐり描きでコマを割る。囲むように描くと仮のコマ（コマの中なら、はめ込み）、コマを横切って描くと仮に割る（白紙のページは基本枠ごと）、コマの間をぐしゃぐしゃに描くと両側のコマをつなげる。仮のコマは鉛筆の線で描かれ、中身・入れ替え・保留・書き出しはふつうのコマと同じ。決まったら「整える」（Shift+K、右の欄、書き出し前の確認）で清書: ほぼ水平・垂直の線をまっすぐに、ほぼそろった辺をそろえ（そのままのコマにも合わせる）、外側の辺を基本枠へ（大きくはみ出していれば裁ち切り）、隣とのすき間を設定のコマ間に（斜めの間白も平行に）。中のラフ線とセリフはコマについていく。選んだコマがあればそのコマだけ、なければ仮のコマ、仮のコマがなければページのコマ全部を整える
- コマ割りの型を当てても、コマの中身（ラフ線・セリフ・塗り・メモ）は読む順に新しいコマへ移る（余った分は最後のコマに）
- 型はコマ数を指定して当てられる（型の見た目のまま、段のコマをつなげる・割って合わせる）。台本の取り込みでも、選んだ型を台本のコマ数に合わせて作る。台本に `型：導入` と書いたページはその型

## セリフとフキダシ

- セリフ: クリックで置く、縦書き・種類（セリフ／モノローグ／ナレーション／描き文字）・話者・文字の大きさ。フキダシは文字に合わせて伸び縮み
- セリフを直す: 右の欄でもその場の書き込みでも、縦書きは右上（読み始め）を動かさずにフキダシが左下へ伸びる（しっぽの先はそのまま）。改行せずに打った長いセリフは、決定したときに句読点や助詞のあとで改行する
- セリフを並べる: コマの操作バーの「セリフを並べる」、ページの「このページのセリフを並べ直す」で、読む順に右上から並べ直す（長いセリフは句読点や助詞のあとで改行。裁ち切りのコマでも基本枠の内側に。斜めのコマで細い端からはみ出すときは、収まるところまで寄せる。ラフに描いた人物の顔（頭のあたり）には重ねず、左か下へよける。アプリが改行したセリフは、改行を変えればよけられるときは改行し直す（手で改行したセリフはそのまま）。よけきれないときは重なりが一番少ないところへ）
- 重なったセリフ: 同じ所をもう一度クリックすると下のセリフを選ぶ
- その場で書く: コマをダブルクリックでコマのメモ（ページの上に札で出る。書き出しには入らない）、セリフをダブルクリックかセリフツールでクリックで文字を直接。書いている間に Tab で決定して読む順で次のセリフ（コマのメモなら次のコマ）へ、Shift+Tab で前へ。ページをまたぐと見開きもめくれる
- 文字の大きさ: 右の欄の文字の大きさの上でホイールを回すと、その場でページに出る。ページの上で Alt＋ホイールでも、選んだセリフの文字の大きさが変わる
- フキダシの形を「〇〇の既定にする」と、その作品でその種類のセリフを作るときの形になる（独白は多角形、など）
- しっぽを付ける: ページの欄か書き出す前の確認から、しっぽのないセリフ全部に。コマのラフの人物（線のかたまり）の頭へ向け、先に話す人ほど右の人物に。同じ話者は同じ向き。ラフがなければコマの下へ
- しっぽ: どのしっぽも直接つかめる（途中をつかんで振る、ひし形で曲げる）。Alt + フキダシからドラッグで足し、先をフキダシに戻すと消える
- セリフのマスク: 操作バーの「マスク」か右の欄の「コマ枠でマスク」で、コマの外に出たフキダシと文字を枠で切る（画面・PDF・CSP のフキダシの線も）

## ラフ線とペン

- ラフ: ペン（筆圧つき）と消しゴム。取り込んだネーム用紙のラフ画像を下に薄く表示（ラフ画像は開くたびに元のネーム用紙から読む。用紙を移したり消したりして読めないと、書き出す前にそのページを知らせ、「ネーム用紙を選び直す」「ラフを除いて書き出す」「やめる」を選べる）
- ペンで Shift を押しながら引くと直線
- 塗り（G、もう一度で塗り方を切り替え）: CSP の塗りつぶしのように 4 つの塗り方がある（左の「サブツール」の欄にも塗り方が並び、クリックで持ち替え・行の ⌨ でキーを割り当て、下のツールプロパティで色と設定を変えられる。上の段と同じ設定）。「塗りつぶし」はクリックした所の、ラフ線とコマ枠で閉じた範囲を塗る（塗りの上をクリックすると、その塗りを持っている色に変える）。「囲って塗る」は囲んだ中の閉じた範囲をまとめて塗る（囲みからはみ出す範囲は塗らない）。「投げなわ塗り」は囲んだ形をそのまま塗る。「塗り残し部分に塗る」はなぞった所の、線と塗りの間に残った小さな隙間を塗る。色は黒（ベタ）・グレー・白。塗り方ごとの設定（上の段）: 隙間閉じ（線の途切れが 0.5・1・2 mm までなら閉じているものとして塗る）、線の中心まで（CSP の「ベクターの中心で塗り止まり」。線の下、線の中心まで塗り、線との間に隙間を残さない）、拡縮（塗る範囲を広げる・狭める mm）、参照（ラフ線とコマ枠／ラフ線だけ／コマ枠だけ。今ある塗りはいつも境目。フキダシは塗りの上に描かれるので境目にしない）、線の下（ラフ線の下に塗る。CSP では「塗り（線の下）」の画像レイヤー。切ると線の上に塗り、ホワイトで線を消すのに使える）。線で閉じた輪の内側は穴として残る。設定は次に開いたときも同じ。塗りを選ぶと右の欄で色と重なり（線の下・線の上）を変えられる
- ラフ線のレイヤー（レイヤーの欄の上）: ラフ線を「人物」「背景」「効果」などに分けて描く。＋で足し、行を押すとペンがそのレイヤーに描く。目で隠す、鍵でロック（描く・消す・選ぶができない）、つまみで濃さ、名前はダブルクリック、↑↓で並び、⤓で下と結合、×で線ごと消す。ページで選んだラフ線は「選んだラフ線をこのレイヤーへ」で移す。CSP へはレイヤーごとの下描きレイヤーで出る（隠したものは隠したまま、濃さもそのまま）
- サブツールの欄（左の欄のいちばん上。CSP のサブツールのように）: ペン・消しゴム・塗りの種類が、描き味の見本の線と太さつきで並ぶ。行をクリックでそのペンを持つ（ほかの道具を持っていてもペンに持ち替える）。ほかのネームで取り込んだペンも下に出て、選ぶとこのネームに入る。行はドラッグで並べ替え。ペンごとに最後に使った太さを覚えていて、持ち替えるとその太さに戻る（ペンの設定でブラシサイズを変えたらその太さ）。タブで「ペン」「消しゴム」「塗り」を切り替えて見られる
- ツールプロパティの欄（サブツールの下。CSP のツールプロパティのように）: いま持っているサブツールの設定。ブラシサイズ（つまみは比で動くので細いペンも細かく選べる・数字）、太さの丸ボタン（「＋」でいまの太さを足し、右クリックで外す。「＋」の右クリックで初めの並びに）、不透明度、手ブレ補正、消しゴムなら消し方。**出す項目はサブツールごとに選べる**: 欄の右下のスパナで「ツールプロパティに出す項目」を開き、CSP のサブツール詳細と同じ分類の項目（ブラシ濃度・アンチエイリアス・硬さ・入り抜き・表示メニューに従いスナップ・ベクター吸着など、チェック・選択・数で変える項目すべて）にチェックを入れるとすぐ出る。右の一覧のドラッグで出す順、「ほかのペンにも使う」で同じ道具のサブツールすべてに同じ項目、「初めに戻す」で初めの項目に。項目の右クリックで「この項目を出さない」。CSP から取り込んだペンは、はじめは CSP のツールプロパティと同じ項目が出る。.sut に書き出すと、ここで選んだ項目が CSP のツールプロパティにも出る（並びは CSP の決まった順になる。CSP で確かめた。CSP の項目の番号がわかっているもの: ブラシサイズ・不透明度・アンチエイリアス・手ブレ補正・スナップ・ベクター吸着。ほかの CSP の項目は元のまま残す）。影響元設定のある項目（ブラシサイズ・不透明度・ブラシ濃度など）は右の曲線のボタンでペンの設定のその項目を開く（筆圧などを使っていると色が付く）。欄の右下の ≡ のアイコンはサブツール詳細（ペンの設定）
- ブラシサイズの欄（はじめは隠れている。欄のアイコンで出す）: CSP のブラシサイズパレットのように、太さの丸ボタンだけを大きく並べる。ツールプロパティとは別の欄なので、反対側の列などに置ける
- ペンごとのキー: サブツールの欄の行の ⌨ を押して（または行を右クリック →「キーを割り当てる」）キーを押すと、そのキーでどの道具からでもそのペン・消しゴムを持つ（例: 1 で Gペン、2 で丸ペン、3 で硬めの消しゴム）。キーは行に出て、右クリックで外す。ほかで使っているキーなら、そちらから外して付け替える。キーはペンの名前ごとにこの PC に残るので、同じペンを入れたほかのネームでも効く。キー設定の「サブツール」と Ctrl+K（ペンの名前で探せる）にも出る
- CSP のペン・消しゴムの取り込み（ペン・消しゴムの段の「取り込み…」、ペンの設定の「CSP から取り込む…」、設定 › ペン・キー、Ctrl+K「CSP のブラシを取り込む」）: 開くとすぐ、この PC の CSP が使っているサブツールの一覧（EditImageTool.todb のコピー）を読み、CSP のサブツールパレットと同じ並び（ツール › グループ › サブツール）で出す。チェックして「取り込む」。ツール・グループの「すべて」でまとめて、上の「まだのもの」「CSP で変わったもの」でも選べる。行には取り込みのようすが出る（取り込み済み・CSP で変わった・ここで直した・両方で変わった）。書き出したサブツール（.sut）も「ファイルを選ぶ」で選べる。太さ・筆圧/傾き/速度/ランダムの影響元とグラフ・入り抜き・手ブレ補正・後補正・先端の素材のほか、CSP の設定はすべてそのまま持ってくる
  - **CSP と合わせる**: CSP の一覧から取り込んだペン・消しゴムは CSP のサブツールと結びついていて、CSP で設定を変えると、ネームを開いたときや Name Studio の窓に戻ったときに合わせる（そのペンで描いた線の見た目も変わる。知らせの「元に戻す」か Ctrl+Z で戻る）。CSP で名前を変えると名前も合わせる（Name Studio で名前を変えていればそのまま）。Name Studio でも設定を直したペンは上書きせず、知らせに名前を出す（一覧で選んで取り込むと CSP のものになる）。設定 › ペン・キーの「CSP で変えたペン・消しゴム」で、自動で合わせる・知らせるだけ・合わせないを選べる。CSP は設定を変えてもすぐにはファイル（EditImageTool.todb）に書かず、サブツールを足す・消したときや CSP を終えたときに書く（CSP で描いている間はファイルが書き換わらなかった）。合わせるのはそのあと
  - **グループを追う**: 一覧のグループの「追う」を入れると、そのグループのまだのものを取り込み、CSP でそのグループに足したペン・消しゴムもあとから自動で取り込む
  - 複製したペンは CSP と結びつかない（このネームのもの）
- ペン・消しゴムの設定（段の「設定…」）: CSP のサブツール詳細と同じ項目（ブラシサイズ・インク・ブラシ先端・入り抜き・補正・消去…）を変えられる。変えるとすぐ上の試し描きに出る（何も描いていないときは弱い→強い→弱い筆圧の見本の線）。影響元設定は筆圧・傾き・速度・ランダムを押して入り切り、最小値とグラフ（点をドラッグ、線の上を押して足す、ダブルクリックで消す）。項目は名前で探せ、× で CSP の初期値に戻す。「新規」「複製」「削除」（元に戻すで戻せる）。「.sut に書き出す…」で CSP のサブツールとして書き出し、CSP のサブツールパレットのメニュー「サブツールの読み込み」で読み込める（素材も入る）。ネームで描いている線の描き味は、太さ・不透明度・影響元・入り抜き・手ブレ補正・後補正・消し方が変わる（ほかの項目は CSP へ戻したときに効く）
- ペンとタブレット（「ペン設定」）: 筆圧カーブ（描いて調節も）、傾き、消しゴム側、サイドボタン、指（1 本指で移動、2 本指で拡大縮小・回転、タップで元に戻す・やり直す、手のひらを無視）、カーソル

## ページと人物

- ページ管理（左の「ページ」の一覧）: ページを右クリックすると、前・後ろに白紙のページを入れる（見開き 2 ページ分も）、複製して後ろに入れる、コピー・切り取り・前／後ろに貼り付け（ほかのネームにも貼れる。資料画像も一緒に、話者は同じ名前の人物に）、1 つ前へ・1 つ後ろへ・先頭へ・最後へ、CSP で 1 枚の見開きページにする、別案を作る、保留にする、削除（最後の空のページだけまとめて消すことも）。一覧の上のボタン（＋前・＋後・複製・保留・削除）でも同じ。Ctrl+クリック・Shift+クリック（Shift+↑↓）で何ページでも選んでまとめて扱える。一覧を押したあとのキー: Insert／Shift+Insert で後ろ・前に挿入、Ctrl+D 複製、Delete 削除、Alt+↑↓ で移動、Ctrl+C／Ctrl+X／Ctrl+V（Ctrl+Shift+V で前に）、Ctrl+A ですべて。どこからでも使える命令は Ctrl+Shift+N（後ろに挿入）・Ctrl+Shift+D（複製）・Ctrl+Shift+Delete（削除）で、キー設定で変えられる。下の帯のページを右クリックしても同じメニュー。見開きは割らない（見開きの途中には入れず、複製・移動は 2 ページ一緒）。入れたページは隣のページのシーン・別案に入る。消すと、見開きのコマの片割れは普通のコマに、そのページの近くに置いた保留コマは前のページの近くに移る。どれも 1 回の Ctrl+Z で戻る。ページは 1 枚は残る
- 保留のページ: ページを「保留にする」と、中身ごとネームから外して左の「保留」に取っておく（続いたページはまとめて 1 件。感情の値も一緒）。「元の場所に戻す」「今のページの後ろに戻す」で戻す。書き出しには出ない
- ページの欄の下で枚数を決めてまとめて最後に足す（1 回の Ctrl+Z で戻る）、ページのメモ、台本（全セリフを読み順に。上の欄でセリフの言葉や話す人で探せる）、登場人物
- 人物: 口調のメモ（セリフを選ぶと右の欄に出る）、数を押すとその人のセリフを並べて見比べ、押すとそのセリフへ
- ほかの一覧もページ一覧と同じ操作: 台本・人物・付箋・保留・レイヤー・シリーズ・サブツールの一覧も、右クリックでメニュー、Ctrl+クリック・Shift+クリック（Shift+↑↓・Ctrl+A）で複数選んでまとめて扱える。一覧を押したあとのキーもそろえてある: Insert／Shift+Insert で後ろ・前に足す、Ctrl+D 複製、Delete 削除、Alt+↑↓ で並べ替え、Ctrl+C／Ctrl+X／Ctrl+V、F2 で名前（文）を直す、Enter で開く、Esc で選択を外す。その一覧で意味のない操作はメニューに出ない。どれも 1 回の Ctrl+Z で戻る
  - 人物: 上のボタン（＋・複製・まとめる・削除）か右クリックで、足す・複製・並べ替え（⋮⋮ をドラッグでも）・コピー（ほかのネームへ貼れる。同じ名前の人がいれば足さない）・削除（セリフの話者は空に）。「選んだ人を 1 人にまとめる」で、台本の取り込みなどで 2 人に分かれた同じ人を、最初に選んだ人に寄せる（セリフ・感情・口調も）。「台本でこの人のセリフを探す」
  - 台本: 何件か選んで右クリックで、話者・種類（セリフ・モノローグ・ナレーション…）をまとめて変える。Ctrl+C で台本の形（■ ページ、名前「…」）でコピーしてほかのアプリへ、F2 かダブルクリックでページの上で直す、Delete で削除。上の「コピー」で選んだもの（なければ全部）をコピー
  - 付箋: 色の四角と「このページ」で絞り込む。選んだ付箋の色をまとめて変える、文をコピー、Delete で済み（外す）、Insert（上の ＋）で今のページに付箋を足して右の欄で書く
  - 保留: 保留のコマと保留のページを選んで、Delete で捨てる、Ctrl+D でコマを複製、Alt+↑↓ で並べ替え。右クリックで置く・選んだコマへ・欄外へ・「このあたり」を今のページに（まとめて）・元の場所に戻す
  - レイヤー: ラフ線・指示のレイヤーは右クリックで複製（線ごと）・名前・隠す・ほかを隠す・ロック・下と結合（Ctrl+E）・このページのこのレイヤーの線を選ぶ。↑↓ で描くレイヤーを選ぶ。その下のコマと中身の一覧は Ctrl・Shift で同じページのものを一緒に選び、右クリックで隠す・ほかを隠す・すべて出す・複製・コピー・保留・削除
  - シリーズ: 話を ↑↓ で選び Enter で開く、右クリックでファイルの場所をコピー・シリーズの一覧から外す（ファイルは残る）
  - サブツール: ペン・消しゴムを右クリックで複製・削除・名前・並べ替え・キー。一覧を押したあと ↑↓ で前後のペンに持ち替え
  - 物語の帯: シーンを右クリックで、名前を直す・シーンのページをページ一覧で選ぶ・ページごと複製・ページごと前後のシーンの向こうへ／先頭へ／最後へ・ポインターのあるページから分ける・前／次のシーンとつなぐ・別案・ページを保留・シーンを消す（ページは残す）・ページごと削除。シーンのない所を右クリックでシーンを足す。話の型の区切りを右クリックで半分に分ける・消す・そのページにビートを足す、ビート（◆）を右クリックで消す
- コマのメモ・ページのメモ・付箋は仕上がりの中に収まるように出る（コマのメモはフキダシを避けて角に）

## 付箋・保留コマ・欄外・資料画像・指示

- 付箋（左の「付箋」）: 全ページの付箋を一覧に。押すとその付箋へ、決まったら「済み」で外す。長い付箋はページの上では頭の 4 行（…）にたたみ、選ぶかポインターを乗せると全文。ページの下の段の「付箋」（Shift+M）で全部の付箋を画面に出す・隠す（隠しても消えない。隠している間は選べず、連続では付箋のために空けていたページの間も詰める。付箋ツールを持つか一覧で選ぶとまた出る）
- 付箋の紐づけ: 付箋ツールでコマやセリフの上をクリックすると、そこに紐づいた付箋（表計算のコメントのように）。付箋はどこへ動かしても線でその場所とつながり、コマやセリフを動かすと付いてくる。選んだ付箋の丸をほかのコマ・セリフへドラッグで付け替え、何もない所で外す。コマのメモの札もドラッグでコマの外へ動かせる（線でつながる）
- 保留コマ（左の「保留」）: コマの操作バーの「保留」で、中身（セリフ・ラフ線・塗り・付箋）ごとページから外し、そのページの上の欄外に置いておく（一覧の「欄外に置く／欄外から下げる」でも出し入れ）。「このあたりのページ」を決めておくと、そのページを開いたときに下の帯とページ一覧に出る。ページへドラッグで戻す（コマの上で離すと中身をそのコマへ合わせて入れる。合わせ方はコマの入れ替えと同じ設定。ドラッグ中は、入れるコマ・置く場所・欄外のどれになるかを枠と言葉で出す）。命令「選んだコマを中身ごと保留にする」にキーを割り当てられる。操作バーの「移す…」で、中身ごと別のページの同じ位置へ
- 欄外（ページの外）: 紙のネームの余白のように、ページの外にも書ける。ペンで考えごとやイメージのラフ、付箋ツールでメモ、資料画像（ページの外へドラッグ、ページの外で貼り付け・ファイルを落とす）、保留コマを置ける。どれもいちばん近いページのものとして一緒に動き、「連続」ではそのページの横・上下だけ欄外の分ページの間が広がる（何もないページどうしの間はそのまま。列と行はそろえたまま、その列・行だけ広がる）。消しゴム・選択・移動もそのまま使える。保留コマは欄外からページへドラッグで置ける（コマの上で離すと中身をそのコマへ）。欄外のものは CSP には書き出さない（CSP のページは紙の端までなので。ページから少しはみ出した線はこれまでどおり書き出す）
- 資料画像（左の「資料」、I）: 写真・背景・前に描いたコマなどをページの下に薄く敷いて、その上にネームを描く。「画像を貼る…」、Ctrl+V（クリップボードの画像。ポインターのあるページへ）、画像ファイルのページへのドロップで貼る。資料ツールでドラッグして動かし、角で大きさ（形はそのまま）、上の段で濃さ・外す（Delete）。画像は大きすぎるものを縮めて（長辺 2400px、写真は JPEG）ネームのファイルに 1 度だけ入る（使っていないものは保存しない）。CSP へは一番下の「資料（ネーム）」下描きレイヤーで出る。PDF には入らない（取り込んだネーム画像は別。下を参照）。画像のデータが壊れているなどで読めないときは、書き出す前にページとファイル名を挙げて「除いて書き出す／やめる」を聞く（`--export-csp` は報告に「注意:」で出す）
- 指示・注釈（R、左の列の「指示」）: ペン入れ以降を人に頼むときの指示書として、ページの上に赤ペンでそのまま描きなぐる（「背景モブ」「ここベタ」「直し」など、矢印や丸も）。ラフ線とは別の「指示のレイヤー」に、いちばん上へ色付きで出る。ペン（手ブレ補正やブラシなし）で描き、ペンの消しゴム側か段の「消す」で指示だけ消せる（消しゴムツールは指示を消さない）。段の「＋色」で青・緑…の色を足すと色ごとにレイヤーが分かれ、人や作業ごとに使い分けられる。ページの下の段の「指示」（Shift+R）で全部の指示を出す・隠す。レイヤーの欄の上の「指示のレイヤー」で、色（丸を押すと次の色）・目・鍵・濃さ・名前・並び・削除。選択ツールで選んで動かす・変形・コピーもできる。小さなページの図（物語の帯・別案）と読む（F5）には出さない。CSP へは色ごとの下描きレイヤー（「指示」など）でいちばん上に、PDF へも色付きで入る（書き出し画面のチェックで外せる。隠している指示のレイヤーは CSP へ隠したまま、PDF には入らない）

## 選ぶ・動かす・元に戻す

- 元に戻す（Ctrl+Z）・やり直す（Ctrl+Y か Ctrl+Shift+Z。上のボタン・3 本指タップでも）、保存（Ctrl+S）。何も変わらなかった操作は元に戻す回数に数えず、やり直せる分も消えない。チェックやスライダーを触った直後とペン・消しゴムの設定の中でも効く（文字の欄の中では、その欄の文字の元に戻す）
- 道具の切り替え: V 選択、K コマ割り、T セリフ、P ペン、R 指示、E 消しゴム、G 塗り、B はみ出し、M 付箋、I 資料。キーを押したままにすると CSP のようにその間だけ持ち替え、離すと元の道具に戻る（押したまま使ったときも。描いている途中で離したら描き終わりで戻る）。短く押すと持ち替えたまま。Space＋ドラッグで移動、ホイールで拡大縮小、Shift＋Space＋ドラッグ（または - と ^）で画面を回す、Ctrl+0 で全体表示、Tab で左右の欄と下の物語の帯を隠してページを窓いっぱいに（もう一度で戻す）。F8 でキーボードが次の欄へ移る（上の帯・左の欄・道具・道具の設定・ページ・ページの送り・物語の帯・右の欄の順に巡る。Shift+F8 で前へ。欄の中は Tab と矢印キー）。キーは「キー設定」で変えられる
- 操作の決まり: Esc は 1 段ずつ戻る（書いている欄 → 変形 → 選択 → 資料画像 → 物語の帯で選んだシーン）。Delete は選んでいるものを消す（物語の帯で選んだシーンも。ページは残る）。ダブルクリックはその場で書く（セリフ・コマのメモ。付箋は右の欄の文字へ）。Ctrl+O で開く・Ctrl+N で新しいネームは、開始画面でも編集中でも同じ。ボタンにポインターを置くと、いま割り当てているキー（「キー設定」で変えたもの）が出る
- 選択の決まり: 選んでいるものは、いつも青く強調して見せる。取っ手（コマの角・しっぽ・変形の枠）とそばの操作バーは選択ツールのときだけ出る。ほかのツールは自分で作ったものだけを選んだままにする（コマ割り＝コマ、セリフ＝セリフ、はみ出し＝はみ出し、付箋＝付箋）。それ以外の選択は、ツールを持ち替えると外れる（見えていない選択に Delete や矢印キーが効くことはない）。一覧・レイヤー・貼り付け・Ctrl+A でほかのツールのまま選ぶと、選択ツールに持ち替える。Esc は 1 段ずつ戻る（変形 → 選択 → 資料画像）
- 選んだもののそばに操作バー。角やしっぽのないもの（ラフ線・塗り・はみ出し・まとめて選んだもの）は選ぶとすぐ変形の枠が出る。左右反転・90° は何を選んでいても効く（コマは中に描いたものと一緒に）。矢印キーはドラッグと同じ動き（コマは中身ごと。資料ツールでは選んだ画像）。Ctrl+C / X / V でコピー・切り取り・貼り付け（ポインターのあるページへ）、Ctrl+A でページのもの（コマ・線・セリフ・塗り・はみ出し）を全部選ぶ
- コマの入れ替え（コマの右上の番号を別のコマへドラッグ。物語の帯・レイヤーの欄でも）: 中身（ラフ線・塗り・セリフ・コマのメモ）だけが入れ替わり、コマの形はそのまま。中身の合わせ方は「設定」›「操作」で選ぶ: 「入れ替え先のコマに合わせる」（初期。コマの幅と高さにそれぞれ合わせて位置を伸び縮み）か「縦横比を保ったまま拡大縮小する」（ラフ線・塗り・セリフの位置をそろって拡大縮小し、コマに収まる大きさでコマの真ん中に置く。はみ出さないかわりに、形の違うコマでは小さめになる）。どちらでもラフ線ひとつひとつの形と、セリフの文字の大きさは変わらない。保留のコマをコマの上に入れるときも同じ設定
- 変形（Ctrl+T か操作バーの「変形」）: コマとフキダシは、角やしっぽの代わりに枠を出して拡大縮小・回転、Ctrl + 角で自由変形。コマは中に描いたものと一緒に。Alt はいつも「吸い付かない」（コマの入れ替えは番号のドラッグで）
- まとめて選ぶ: Shift + クリックで足す・外す、Shift + ドラッグ（または何もない所からドラッグ）で囲んだものを選ぶ。選んだコマ・線・セリフ・塗り・はみ出しをまとめて動かす・拡大縮小・回転・自由変形・コピー・削除（コマは中に描いたものと一緒に）
- レイヤー（左の欄）: 見開きのコマごとに中のセリフ・ラフ線・塗り（CSP のコマ枠フォルダのように）。行で選ぶ、目で画面から隠す、行をコマへドラッグで移す

## CLIP STUDIO PAINT へ書き出す

- 書き出し（「書き出す…」）
  - CSP のページ: ページごとの .clip（ラフ線・コマ枠・フキダシ・セリフ・取り込んだラフ画像を別レイヤー）と作品ファイル（.cmc）。ネームの基本枠をひな形の基本枠に合わせる
  - ひな形なしで書き出せる（既定の「ツールで設定する」）: 用紙（商業誌 B4・A4・B5・A5 か手入力）・キャンバス・仕上がり・裁ち落とし・基本枠（大きさとずらし）・解像度・1 ページ目の左右・作者名・ノンブルの開始番号・作品情報のフォント・サブタイトル・作品名と作者名の位置・ページ番号・見えるノンブル（位置・色・フチ・書式・間隔・大きさ）を書き出し画面で決めると、アプリに入っている CSP 製の白紙からページと作品ファイルを作る（設定はネームに保存。綴じ方はネームの読む向き）。CSP で保存したひな形を使うこともできる（「CSP のひな形を使う」）
  - 書き出す前の確認: フキダシの重なり・コマの外のセリフ・コマからはみ出したセリフ・仕上がりの外・しっぽのないセリフ・ラフの顔にかかるセリフを一覧にし、押すとそのセリフへ。はみ出しは「はみ出したセリフのコマを並べ直す」でまとめて改行し直す。顔にかかるセリフは「顔にかかるセリフをずらす」で、そのセリフだけ顔とほかのフキダシをよけてずらす（よけきれないコマは並べ直す）
  - PDF: 全ページを 1 つの PDF に（右綴じなら右から開く指定つき）
  - ミニネーム: 全ページを 1 枚の PNG・JPEG か 1 ページの PDF にまとめる（全体を見渡す・印刷する・送る用）。見開きを読む順に並べ（右綴じは右上から左へ、段ごとに下へ。縦スクロールは列に）、ページ番号と題名を付けられる。仕上がりかキャンバス全体か・解像度・横に並べる数（おまかせは A 判の横長に近く）を選べる。大きすぎるときは解像度を下げて知らせる
  - 台本: ページ・コマ・話者つきのテキスト
- 書き出しの設定はネームごとに覚える（書き出し先・ひな形・コマの書き出し方・レイヤーの選択・PDF/台本のファイル）。次に書き出すときはそのネームの前回の設定から始まり、別のネームの書き出し先を引き継いで上書きすることはない。「前回と同じ設定で書き出す」（Ctrl+Shift+E）で、何も聞かずに前回と同じ書き出しをもう一度（CSP で描き進めたページを上書きしそうなときだけ確認する）。PDF・ミニネーム・台本は、保存のダイアログで選んだことのある場所にだけ書く（覚えている場所がそうでないときは、保存先をもう一度聞く）。書き出している間は「中止」でページの切れ目で止められる（PDF は何も書かずに、CSP は書き終えたページまでで止め、作品ファイルは前のまま）

線とセリフを CSP で直せるベクター・テキストのレイヤーにするには、CSP がそのレイヤーを作った .clip を見本にして写します。
ひな形、`--donor`（書き出し画面の「見本のページ」）、取り込み元のネーム用紙、ひな形と同じフォルダーのページの順に探し、
どれにもなければ csp-format に内蔵の見本（線 1 本とテキスト 1 つのページ）を使います。CSP が保存した空のページだけをひな形にしても、線とセリフは編集できるレイヤーになります。

ラフ線（はみ出しのラフ線、ネーム用紙のラフも）は下描きレイヤー・不透明度 50% で書き出します（ラフ線のレイヤーを分けたときは、レイヤーごとにその名前で、濃さはその割合をさらに掛けて）。CSP でその上に新しいレイヤーを作ってペン入れでき、塗りつぶしの参照や画像の書き出しには入りません（画面のチェック、`--no-draft-rough` で普通のレイヤーに）。

塗り（線の下）にした塗りは、そのページだけ、いちばん下の画像レイヤー「塗り（線の下）」に書き出します。線の上の塗りはこれまでどおり「コマの塗り・効果」に入ります。

コマのメモとページのメモは、いちばん上の下描きレイヤー「メモ（ネーム）」に、アプリの画面と同じ札で書きます（ペン入れ中に見られ、印刷されない。付箋は書かない。画面のチェック、`--no-notes` で書かない）。

指示（指示ツールで描いたもの）は、その上に指示のレイヤーごと（色ごと）の下描きレイヤーで、描いた色のまま書きます（ほかの下描きレイヤーと違って不透明度は半分にせず、レイヤーの欄の濃さのまま）。名前はレイヤーの欄の名前（はじめは「指示」）。指示のないレイヤーは書かず、隠している指示のレイヤーは隠したレイヤーで書きます（画面のチェック、`--no-marks` で書かない）。

コマごとのフォルダー＋レイヤーマスク: 書き出し画面の「コマ」で選ぶか `--panel-masks` で、コマごとにフォルダー「コマ1」「コマ2」…（読む順）を作り、コマの形にレイヤーマスクを付けます。マスクはコマ（裁ち切りの辺はキャンバスの外まで）と、そこにかかるはみ出しの範囲で、上に重なるはめ込みのコマの下は隠します。コマのラフ線（点の多くがそのコマにある線）と空の「ペン入れ」レイヤーがフォルダーに入り、コマの外に出た線は切らずにマスクで隠すだけなので、CSP でマスクを描き足せば飛び出しになります。どのコマにもない線とはみ出しのラフ線、コマ枠の線はこれまでどおりフォルダーの外です。見開きページでは、見開きのコマの両半分を 1 つのフォルダーにします。見本のページは要りません（フォルダーとマスクの形式は [csp-layer-mask.md](csp-layer-mask.md)）。

コマ枠フォルダー（試験中）: 画面の「コマ」でコマ枠フォルダーを選ぶか `--frame-folders` で、コマを CSP のコマ枠フォルダー「コマ」の枠にし、その中に空の「ペン入れ」レイヤーを入れます（そこに描くとコマの外にはみ出しません）。枠線の太さはネームのとおり、裁ち切りの辺はキャンバスの外まで伸ばします。マスクと枠線の画像は CSP が開くときに枠から描きます（CSP 自身もそう保存します）。コマ枠フォルダーの設定は、コマ枠フォルダーを作って保存した CSP のページ（仕上げた原稿など）を見本のページに選ぶとそこから写します。点線・波線・枠なし・はめ込み・見開きの半分・はみ出しで切れるコマ・のど側の裁ち切りは、これまでどおり「コマ枠」ベクターレイヤーの線にします。

### セリフだけ反映

セリフだけ反映（ペン入れを始めたあとで台本を直したとき）: 書き出し画面の「セリフだけ反映…」か `--update-dialogue` で、前に書き出したフォルダーのページ（CSP で描き進めたもの）に、ネームで変わったセリフとフキダシだけを入れます。描いたレイヤーやほかのレイヤーはそのままです。
- 同じセリフのテキストレイヤーは触りません（CSP で動かした位置もそのまま）。変わった・消えたセリフは消さずに隠して名前の頭に「（旧）」を付け、新しいセリフをその上に足します（見比べてから CSP で消せます）
- フキダシ（「フキダシ」ベクターと「フキダシの塗り」）は、ネームで形が変わったページだけ同じように入れ替えます
- 「メモ（ネーム）」レイヤーは、ネームのメモが変わったページだけその場で描き直します（`--no-notes` で触らない）
- 指示のレイヤー（「指示」など）も、ネームの指示が変わったページだけその場で描き直します。前の書き出しになかった指示はいちばん上に下描きレイヤーで足します。隠している指示のレイヤーは触りません（`--no-marks` で全部触らない）
- 書き出したときの中身を書き出し先の `.name-studio-export.json` に控えておき、CSP で直したセリフ（ネームでは変えていないもの）と CSP で足したテキストはそのままにします。フキダシを CSP でもネームでも直したときはネームのものにし、知らせます
- 反映したあと、変えたページ（CSP でも直していた・ページやレイヤーがなかったページは目立たせて）を並べ、押すとそのページに移ります。次に書き出し画面を開いたときも、そのネームの前回の分が出ます。書き出し先の `name-studio-反映の記録.txt` に、回ごとの日時・結果・ページを書き足していきます（メモ帳で読めます）
- 変える前のページは書き出し先の `name-studio-backup/日時/` に写します。書き出したときと同じひな形・ページ数・見開きで反映してください。CSP でページを開いているときは、保存して閉じてから

### CSP のセリフを読み戻す

CSP のセリフを読み戻す（ペン入れ中に CSP でセリフを直したとき）: 書き出し画面の「CSP のセリフを読み戻す…」か `--read-dialogue` で、前に書き出したフォルダーのページから、CSP で直した・足した・消したセリフをネームに入れます。ネームと CSP の両方で直さなくて済みます。
- 書き出したとき（反映したとき）の中身と比べて、CSP で変わったセリフだけを入れます。ネームで変えたところはそのままで、両方で変えたセリフはネームのものを残して知らせます
- 直したセリフは、似ている言葉か同じ場所のものを組にして書き換えます（縦書きの右上はそのまま）。足したセリフは CSP の位置に、そのコマのセリフとして入れます
- 入れる前に、変わったセリフを 1 件ずつチェックを付けて並べます（はじめは全部に付いています）。外したものはネームのままで、次の「セリフだけ反映」で CSP もネームに合わせます。元に戻すは Ctrl+Z。命令パレットの「CSP のセリフを読み戻す」からも、そのネームの前回の書き出し先で始められます。`--read-dialogue` はネームのファイルに保存します
- 読み戻したセリフは、次の「セリフだけ反映」でそのまま残ります（言葉に合わせてフキダシだけ入れ替わります）。書き出したときの記録がないページ（前のバージョンで書き出したもの）は読み戻しません

## AI に相談する

- 右の欄の「相談」（命令パレットで「相談」）: ネームで行き詰まったとき、AI にネームを見せて相談する。相手は **Claude Code**・**Codex**（どちらもこの PC に入れて、サインインしてあるもの）か、**ローカル LLM**（Ollama・LM Studio・llama.cpp など OpenAI 互換の API）。上の選び欄で切り替え、「接続…」で場所・モデルを決める（Claude Code と Codex は自動で探す。見つからなければ claude.exe / codex.exe を「参照…」で。動かすのは、自動で見つかったものか「参照…」で選んだものだけ）。モデルと effort（考える深さ）は、それぞれのツールが返す一覧から選ぶ（手で打たないので名前の打ち間違いが起きない。新しいモデルが出たら ↻ で取り直す。場所・サンドボックス・API キー・スキルは「詳しく」を開くと出る）。一覧にないモデルや、そのモデルが選べない effort が残っていれば、送る前に知らせて止める。AI の返事は Markdown（見出し・太字・箇条書き・表など）で表示する。相談は自動で残り、「履歴」の一覧から開くと、その話の続きとして話せる（Claude Code・Codex は前の会話をそのまま覚えている。「ほかのネームも」で別のネームの相談も出る。「消す」を 2 回で一覧から消す）。相談にはネームの要約をそのまま付けて送るので、AI がファイルを読めないときも話は進む。Windows の Codex は「詳しく」の「サンドボックス」で囲いを選べる（既定は mxc。Codex の設定の elevated は、Codex アプリを開いていると準備に失敗してファイルを読めないことがある）
- 最初の質問で、ネームを言葉にしたもの（構成・人物・シーン・ページごとのコマと演出メモとセリフ）、ネームの写し、ページの絵（ラフ・コマ・フキダシ。「ページの絵も見せる」で外せる）を相談用のフォルダーに置いて渡す。いま開いているページも伝える。次の質問は同じ会話の続き。ネームを変えたあとの質問では、新しい中身を置き直して「読み直して」と伝える。「新しい相談」で会話を終えて始め直す。困ったら下の「行き詰まった」「このページのコマ割り」などの決まった質問から
- AI は相談相手で、ネームを勝手に変えない。案を具体的に出すときは「変更の案」のカードになる（何が変わるかを文で。できない案は理由が出て当てられない）。「当てる」でネームに当たり、Ctrl+Z 1 回で全部戻る。「JSON をコピー」で案そのものを写せる
- Claude Code と Codex は読むだけの設定で動かす（ファイルの書き換え・ネットは使わせない。相談用のフォルダーの中のファイルを読むのと、ネームを読むスキルを動かすだけ）。相談用のフォルダーは `%LOCALAPPDATA%\<アプリ>\ai-sessions` に作り、14 日たったものから消す。ローカル LLM の API キーは Windows の資格情報マネージャーに入れ、設定のファイルには書かない（Ollama などキーの要らないものは空のまま）
- **ネームを読み書きするスキル**（Claude Code / Codex 用、`skills/name-studio`）: アプリを開かなくても、AI がネームのファイル（.namestudio）を読んで相談に乗ったり、セリフ・コマ割り・ページ・付箋・人物・シーン・構成を直したりできる。「接続…」の「Claude Code に入れる」「Codex に入れる」で、それぞれのスキルの場所（`~/.claude/skills`・`~/.agents/skills`）に入れる（「フォルダーに書き出す…」で好きな所にも）。動かすには Node.js 18 以上が要る。中身は `node scripts/namestudio.mjs brief|script|check|ops|apply|new`。書き換えるときは全部を確かめてから、前の中身を `.bak` に残して書く。アプリで開いているネームを AI に直させたときは、閉じてから開き直す

## 作業を失わないために

- 自動保存: 変更が止まって 3 秒後（続けて変えていても 30 秒ごと）に、ファイルか控えに書きます（秒数は設定の「保存」で変えられます）。中身が変わっていなければ書きません（何も変えない操作や、変えて元に戻しただけのときも、ファイルも版の履歴もそのまま）。版の履歴は 1 ネームあたり 300 MB まで（古い自動保存の版から消し、新しい保存の版 10 個は必ず残す）
- 保存できない細かい不整合（消した人物を指すセリフ、重なった id など）は、保存の前に直して何を直したかを出します（元に戻すで戻せます）。自動保存でそういう問題が見つかったときも控えには必ず残し、上に警告を出します
- うまくいかなかったときは、上の知らせに次にできることのボタンが出ます。保存できなかった: 「もう一度」（同じ場所に）・「別の場所に保存」・「フォルダーを開く」（エクスプローラーで保存先を見る）。自動保存できなかった: 「今すぐもう一度」。開けなかった: 「別のファイルを開く」・「フォルダーを開く」。更新できなかった: 「もう一度」。書き出しの画面では、書き出せなかったとき「もう一度」「書き出し先を開く」、書き出せたとき「フォルダーを開く」（CSP の作品ならその場所）が出ます
- うまくいかなかったこと（開けない・保存できない・書き出せない など）は、右下の知らせに赤い字と ⚠ で出て、ページの上にも数秒出ます。何をすればよいかを言葉で言い（例: ほかのアプリがファイルを開いているので、閉じてからもう一度）、右下の知らせを押す（か、そこで Enter）と、もとのエラーの文も読めます。次の知らせが出るまで残ります
- 操作の途中で問題が起きたら、その操作を取り消して（ネームが中途半端な状態で残らない）上に知らせ、`%LOCALAPPDATA%\<アプリ>\logs\name-studio.log` に記録します
- 起動したとき、保存しないまま終わったネームがあれば、更新の確認より先に全部を一覧にします（作品名・ページ数・いつの自動保存か・保存先。読めなくなった控えも理由と一緒に）。1 件ずつ「復元する」「削除…」（確かめてから）を選べ、「あとで」（閉じる）なら控えは残って次の起動でまた出ます
- 保存はアプリが書いた中身をそのまま書くので、新しい版で足した項目が古い仕組みで消えることはありません。新しい版で保存したネームを古い版（「前の版に戻す」など）で開くと、その版が知らない項目は画面と書き出しに出ないので、上に知らせます（この知らせより前の版では出ません）。新しい版で足された選択肢（フキダシの形など）があるネームは開かず、更新するよう知らせます。点の座標は 0.01 mm（筆圧などは 0.001）で保存します

## CSP のネーム用紙を見る・分ける

- CSP のネーム用紙（.clip）を開いて、全体表示と右綴じの見開き表示で見直す
- ページ枠（テンプレートの四角形）から 1〜N ページを自動で割り当てる
- レイヤーの表示切り替え、ページごとのセリフ一覧（縦書きで表示）
- ネーム用紙をページごとの .clip と作品ファイル（.cmc）に書き出す（レイヤーを保ったまま）
