# コマ割りとフキダシの表現パターン

コマ割りは四角を割るだけでは作れない。このメモは、ユメノストラ第1〜3話の原稿と一般的な漫画の作法から集めた表現パターンを、name-studio のデータでどう表すかをまとめたもの。

## 解析した素材

- ユメノストラ第1〜3話の完成原稿（.clip、計 95 ページ分）。`name-studio-cli` で各ページの構造を JSON にし、縮小画像を見開きで並べて見た。
- 原稿の作り:
  - 1ページにコマ枠フォルダーが1つ（「コマ 1」）あり、その中に全コマが入っている。
  - セリフは1〜7個のテキストレイヤーにまとまっている。フキダシはテキストレイヤーの中にある。
  - はみ出す絵は、コマ枠フォルダーの外のフォルダーに描かれている。

## コマ割りの語彙

| 表現 | 原稿での使われ方 | name-studio での表し方 |
| --- | --- | --- |
| 裁ち切り | 導入の風景や一枚絵を上や横に裁ち切る | `Panel.openEdges`（描かない辺）。インスペクターの「裁ち切り 上・右・下・左」で、コマの辺をページの外まで伸ばして開く |
| はみ出し（突き抜け） | 全身像や決めの動きがコマ枠をまたぐ | `Page.breakouts`（はみ出し領域）。「はみ出し」ツール（B）で投げ縄を描く。中の枠線は描かれず、そこから描き始めたペン線は `Stroke.over` で枠線の上に乗る |
| はめ込みコマ | 大ゴマの角に小さいコマを重ねる | `Panel.z` と白い塗りの `Panel.fill`。重なった下の枠線は自動で切る |
| 斜めの間白 | アクションの勢い | 斜めにコマを割る（Alt）か「⟲/⟳ 2°」 |
| 細い空コマ（間） | 沈黙や余韻 | 型「間（細い空コマ）」 |
| 黒ベタの帯・黒コマ | 回想や場面転換 | `fill: black`。白抜きのセリフ（`Line.inverted`）と組み合わせる |
| 枠なし・枠線の種類 | 回想（波線）、夢や記憶（破線）、強調（太線）、枠なしの一枚絵 | `Panel.border`: solid / thick / dashed / wavy / none |
| 背景の効果 | 集中線、スピード線、フラッシュ、キラキラ | `Panel.effect`。ネーム用の目印として描く |
| 見開きのコマ | 見せ場の大ゴマ、決めの一枚絵 | `Panel.spread`。「見開きにする」で、のどの側を裁ち切りにし、向かいのページに左右反転したもう半分を作る。2つの半分は同じ `spread` を持つ |
| 演出メモ | 俯瞰、アップ、間など | `Panel.note` |

ページ全体の土台には「コマ割りの型」を9種類用意した。ページのインスペクターから当てる。

- 基本の4段
- 3段（2・1・2）
- 導入（上を裁ち切り）
- 大ゴマ＋はめ込み
- 斜めの間白（アクション）
- 縦長の連続（動きのコマ送り）
- 間（細い空コマ）
- 回想の帯（ベタと交互）
- 1ページ大ゴマ（全面裁ち切り）

## フキダシの語彙

| 表現 | 意味 | name-studio での表し方 |
| --- | --- | --- |
| 楕円・角丸 | 普通のセリフ | `balloonShape`: ellipse / rounded |
| 四角 | ナレーション | box（ナレーションの既定） |
| 多角形（六角形） | 独白、心の声、回想（ユメノストラで多い） | polygon |
| モコモコと泡のしっぽ | 思考 | cloud と `TailStyle` bubbles（モノローグの既定） |
| トゲ・爆発 | 叫び、怒鳴り | spike / burst |
| ウニフラ | 衝撃、驚き | flash |
| ふるえ | 恐れ、弱気 | wavy |
| 電子音とギザギザのしっぽ | 電話、機械、テレビ | electric と zigzag |
| 破線 | ささやき、ひそひそ | dashed |
| フキダシなし | 小書き、つぶやき、描き文字 | none。種類「小書き」（`LineKind::Aside`）の既定 |
| 複数のしっぽ | 同時に話す声 | `Line.tails` に2本以上 |
| 画面外へのしっぽ | コマの外にいる話者 | しっぽの先はどこへでも置ける。線のしっぽ（line）は遠くの話者 |
| 連結フキダシ | 1人の話者が間を置いて続けるセリフ | `Line.linkTo`。輪郭をくびれでつないで1つにする |
| 強調・白抜き | 決め台詞、黒地の上のセリフ | `Line.emphasis`（太字）、`Line.inverted`（黒地に白文字） |
| 枠をまたぐフキダシ | コマとコマの間の時間をつなぐ | フキダシはコマに縛られないので、そのまま置ける |

`balloonShape` を省くと、セリフの種類から形が決まる。CSP から取り込んだフキダシは `custom` として、取り込んだ輪郭をそのまま残す。

## データの変更（形式バージョン 2）

新しい項目はすべて省略でき、既定値なら保存しない。

- `Panel`: `border`, `openEdges`, `fill`, `effect`, `z`, `note`, `spread`
- `Page.breakouts`: `{ id, shape, note }`
- `Line`: `balloonShape`, `tails`（`{ tip, style }`）, `linkTo`, `inverted`, `emphasis`
- `LineKind`: `aside` を追加
- `Stroke.over`

`line.balloon` には、しっぽと連結を含まない元の輪郭だけを入れる。しっぽと連結は描くたびに作る。形式1のファイルを開いたとき、40点の楕円でも4点の四角でもない輪郭は `custom` にする。

## CSP への書き出し

レイヤーは下から次の順に並ぶ。

1. ラフ線
2. コマの塗り・効果（いつもラスター）
3. コマ枠
4. はみ出し（ラフ線）
5. フキダシの塗り（ベクターで書き出すときだけ。ラスター）
6. フキダシ
7. セリフ

ベクターで書き出すときの扱い:

- 開いた辺と、上のコマやはみ出しに隠れる枠線は書き出さない。
- 破線や波線は線の形に直してから書き出す。
- 白抜きのセリフは、テキストレイヤーの文字色を白にする（既定色の属性 0x22 と、それより優先されるフォントランの色の両方）。
- しっぽと連結フキダシは、1本の輪郭として書き出す。

## まだできないこと

- 見開きのコマは、ページごとの半分として書き出す（CSP の見開きページにはしない）。半分の形は別々に編集する。
- CSP のフキダシ素材（フキダシレイヤーの種類）としての書き出し。
